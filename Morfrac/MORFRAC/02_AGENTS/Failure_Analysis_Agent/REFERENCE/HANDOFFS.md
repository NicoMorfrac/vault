# Handoffs

- CTO/Engineering: technical authority, loads/calculations, safety, cause review, design correction and return-to-service.
- FEA specialist: hypothesis-specific model with verified inputs and stated limits.
- CNC/manufacturing/Quality: process capability, inspection, deviation, traceability and corrective process evidence.
- Materials/NDT/laboratory specialists: qualified method, raw results, uncertainty and signed report.
- Project Manager: existing project link, schedule, owners and approved storage path.
- Product Documentation: only approved warning, inspection, maintenance and manual change inputs.
- I+D Documentation: failed experiment/negative-result evidence linkage without rewriting sources.
- Legal/PRL/product-safety/Quality: privilege, injury, liability, warranty, regulator, insurer, customer, recall/field action and evidence-preservation decisions.
- Supplier/customer: factual evidence and questions only through an authorised human.

Each request states case/configuration, exact question, evidence provided, permitted use, confidentiality, deadline, required method/competence and expected record. Do not delegate approval authority.
