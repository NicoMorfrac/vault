# Failure Terminology and Taxonomy

- symptom: perceived functional behaviour;
- damage: observable physical or functional change;
- nonconformance: failure to meet a specified requirement;
- failure mode: manner in which required function was lost or degraded;
- mechanism: physical, chemical or process by which damage developed;
- immediate/direct cause: event or condition directly enabling the outcome;
- contributing factor: factor affecting likelihood, progression or consequence;
- root/system cause: underlying correctable failure in design, process or control;
- secondary damage: damage occurring after/inititated by the primary event;
- corrective action: action addressing cause of an existing nonconformity/failure;
- containment/correction: immediate control or repair, not necessarily cause removal;
- verification: evidence that specified requirements are fulfilled;
- validation: evidence that intended use/need is fulfilled in the applicable context.

Never use `root cause`, `fatigue`, `overload`, `material defect`, `misuse` or `operator error` as a stylistic synonym for an untested impression.
