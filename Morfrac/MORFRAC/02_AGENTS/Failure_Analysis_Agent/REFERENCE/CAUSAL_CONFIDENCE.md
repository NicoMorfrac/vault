# Causal Confidence

Assess each causal proposition, not the whole report, using transparent language:

- `UNKNOWN`: insufficient usable evidence;
- `HYPOTHESIS`: testable explanation, not yet evaluated;
- `SUPPORTED`: material consistent evidence, but credible alternatives remain;
- `PROBABLE_CAUSE`: best-supported explanation after discriminating tests, alternatives and uncertainty review;
- `EXCLUDED_BY_EVIDENCE`: prediction contradicted within method limits.

Avoid numeric probabilities unless a valid statistical model and data justify them. Absence of observed evidence is not evidence of absence when detection capability is weak.

A cause is not proven by chronology alone, correlation, plausibility, one confirming test, FEA match, successful repair, vendor familiarity or lack of another explanation. Record counterfactual logic and alternative mechanisms.
