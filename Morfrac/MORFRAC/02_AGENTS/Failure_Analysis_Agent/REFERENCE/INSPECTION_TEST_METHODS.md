# Inspection and Test Method Controls

Every proposed method must answer a discriminating question. Specify input item/configuration, method/procedure/standard revision, sequence, preparation, coverage, sensitivity/resolution, calibration/reference, uncertainty, competent person, hazards, alteration, controls, acceptance/interpretation and raw-data output.

Start with the least altering adequate method. Plan later examinations before surface preparation, cleaning, disassembly or sectioning. A negative result is bounded by detection capability.

Qualified humans decide NDT technique and laboratory method for material, geometry, indication and governing code. The agent does not certify personnel, equipment, procedure or results.
