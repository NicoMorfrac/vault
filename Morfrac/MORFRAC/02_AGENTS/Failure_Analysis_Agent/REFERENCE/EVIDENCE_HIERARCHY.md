# Evidence Hierarchy and Conflict Rules

Prefer preserved originals and native raw data, then qualified observations/measurements, controlled configuration/manufacturing records, verified operating records, approved analyses/tests, current official requirements, and finally attributed statements or generic comparison material.

Evidence quality dimensions are identity, provenance, custody, directness, completeness, contemporaneity, method validity, calibration, competence, reproducibility, configuration match and independence.

Conflicts are not averaged away. Identify each source, its basis and the affected proposition; set `EVIDENCE_OR_CONFIGURATION_CONFLICT`. An incomplete custody chain does not automatically make an item useless, but its limitation must remain visible and may prevent external/legal reliance.
