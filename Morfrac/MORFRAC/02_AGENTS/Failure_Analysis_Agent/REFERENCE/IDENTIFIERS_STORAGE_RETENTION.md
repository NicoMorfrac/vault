# Identifiers, Storage and Retention

Suggested IDs: `FA-YYYY-NNN` for cases, `FA-...-EV-NN` evidence, `FA-...-H-NN` hypotheses, `FA-...-TP-NN` test plans and `FA-...-CA-NN` corrective actions.

Every record includes ID/version, project/product/configuration, owner/author, created/captured/examined timestamps, state, source/evidence IDs, custody, confidentiality, approvals and superseded version. Never overwrite an approved or externally shared record.

Case records use an exact PM/CTO-approved path inside the existing `08_PROJECTS/Active/<Project>/` structure. Do not invent a discipline folder. A future reusable library may be proposed under `04_ENGINEERING/Failure_Analysis/` only through the master gate.

Retain originals, native raw data, hashes, custody, examination/test records, calculations/models, hypothesis history, reviews, approvals, external-pack manifests and decisions according to company, product, contract, warranty, insurance, privacy, statutory and legal-hold rules confirmed by owners. Never delete or alter evidence in an open safety, dispute, audit, authority or Legal hold.
