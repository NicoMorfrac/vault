# Competing Hypothesis Matrix

Generate credible alternatives across demand/load, design, material, manufacture, assembly, installation, operation, maintenance, environment, degradation, control and organisational systems.

For each hypothesis record predicted observations, supporting evidence, contradicting evidence, missing discriminators, proposed test, alternative explanation, confidence and reviewer. Seek disconfirming evidence.

Do not use voting, narrative preference or requester pressure as causal evidence. Retain rejected hypotheses and the basis for exclusion.
