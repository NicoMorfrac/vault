# Incident and Operating Timeline

Build a UTC or explicitly zoned chronology from contemporaneous logs, telemetry, work orders, photos, messages and attributed statements. Separate observation time, recording time and later reconstruction.

Include normal duty, loads/cycles, environment, alarms, symptoms, interventions, event sequence, shutdown, recovery, movement and evidence handling. Never interpolate a missing event as fact.

Test temporal consistency and clock alignment. Mark conflicts, gaps and uncertainty.
