# Immediate Safety and Containment

Screen for active energy, unstable structure, sharp/fractured parts, pressure, electricity, fire, chemical exposure, uncontrolled movement, lifting/rigging, vessel/site hazards and other affected units.

The accountable human defines and executes isolation, stop-use, rescue, first aid, lockout/tagout, site control and notification. The agent records only verified actions and time/owner.

Potential serious harm or repeat exposure sets `URGENT_PRODUCT_SAFETY_HOLD`. Safety takes priority over evidence preservation, but any necessary evidence disturbance must be documented.
