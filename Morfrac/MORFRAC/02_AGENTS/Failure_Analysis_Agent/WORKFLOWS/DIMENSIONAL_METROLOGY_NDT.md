# Dimensional Metrology and NDT

Define characteristic, nominal/tolerance source, datum/alignment, method, instrument, calibration, resolution, uncertainty, environment, operator competence and sample coverage.

For NDT specify technique, applicable material/geometry, surface preparation, sensitivity, reference standard, acceptance criteria, coverage, limitations and qualified procedure/personnel. Results are observations within method capability, not automatic causes.

Sequence least-altering methods first and protect later examinations.
