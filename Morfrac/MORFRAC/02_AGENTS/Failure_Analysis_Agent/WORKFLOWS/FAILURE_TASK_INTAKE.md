# Failure Task Intake

Set `FAILURE_TASK_INTAKE_REQUIRED` until requester, case decision owner, event date/location, product/project, item identity, present location, safety status, injuries/damage, affected population, current containment, confidentiality, deadlines and intended output are known.

Classify the task as field failure, manufacturing nonconformance, test failure, degradation, underperformance, near miss, injury/incident support, supplier/warranty investigation or recurring trend. Record the exact question and prohibited actions.

Do not delay an urgent safety escalation while completing ordinary intake.
