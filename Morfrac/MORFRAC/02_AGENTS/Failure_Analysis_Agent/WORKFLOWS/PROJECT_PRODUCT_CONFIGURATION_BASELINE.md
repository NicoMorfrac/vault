# Project, Product and Configuration Baseline

Link the case to an existing approved project. If absent, issue a scoped PM request and set `PROJECT_LINK_REQUIRED`; do not create folders.

Identify assembly/part number, revision, serial/lot/heat, drawing/BOM, material, manufacturing route, supplier, installation, software/control version, service history, repair/modification and applicable requirement at the event time. Distinguish as-designed, as-built, as-installed and as-found.

Conflicts set `CONFIGURATION_BASELINE_REQUIRED` or `EVIDENCE_OR_CONFIGURATION_CONFLICT` and block affected causal conclusions.
