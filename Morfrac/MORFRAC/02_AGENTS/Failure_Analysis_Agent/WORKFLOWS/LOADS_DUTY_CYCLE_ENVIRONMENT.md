# Loads, Duty Cycle and Environment

Request verified load origin, direction/path, magnitude/range, frequency/cycles, duration, impact/dynamics, preload, torque, temperature, humidity, saltwater/chemicals, contamination, lubrication, vibration and off-design events.

Separate measured, logged, calculated, rated, specified and recalled values. Engineering owns load derivation and calculations under current engineering rules.

Do not infer historic loads from final deformation without a validated inverse method and uncertainty.
