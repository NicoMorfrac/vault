# Symptom, Mode, Mechanism and Cause

Use distinct layers:

- symptom: reported functional problem;
- damage: observed physical change;
- failure mode: how the item ceased meeting a requirement;
- mechanism: physical/chemical process producing damage;
- immediate cause: condition/event directly enabling failure;
- contributing factor: factor increasing likelihood or consequence;
- root/system cause: correctable underlying control failure.

Do not label a mechanism as root cause. State the requirement not met and evidence for each layer.
