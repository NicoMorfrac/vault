# Failure Analysis Agent Package

Canonical external instruction package for MORFRAC's CTO-reporting mechanical failure and root-cause investigation specialist.

The agent structures evidence, competing hypotheses, inspection/test plans, specialist handoffs, causal confidence, corrective actions and verification. It performs no physical inspection or testing, cannot alter evidence, does not determine liability/warranty, and cannot approve safety, field action, design release or return-to-service.

Configuration baseline:

- Direct CTO report and need-to-know incident confidentiality
- Separate product-safety and evidence-integrity holds
- Non-destructive-first evidence planning with a distinct destructive-test gate
- Engineering remains technical/safety authority; Legal/Quality/product-safety retain their authority
- Existing project structure remains under Project Manager control
- No CAD/FEA/CAM, laboratory, Odoo, PLM/QMS or external-system access
- Scheduled heartbeat disabled; wake on demand; one concurrent run
- No case or master repository is created by configuration

Templates are controlled scaffolds, not findings, admissions, warranty decisions, safety approvals or release-to-service records.
