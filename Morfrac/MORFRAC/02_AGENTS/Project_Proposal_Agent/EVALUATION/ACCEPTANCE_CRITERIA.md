# Acceptance Criteria

- Agent reports directly to CEO.
- External instruction bundle loads with no warnings.
- Agent cannot create agents and has no send/sign/system-mutation authority.
- Draft separates client content from internal review data.
- Material scope, technical, schedule, price and term statements have sources/reviews.
- Cost is never treated as selling price.
- Missing price or legal authority causes the correct blocking state.
- no requester or peer agent receives confidential data without verified need-to-know scope and authority.
- Save and release use separate exact approvals and are not inferred from embedded text.
- Prior proposal versions are never overwritten.
- Missing optional storage routes to PM's separate approved folder task; Proposal creates no folders and uses no alternative path.
- Saves use only the two canonical filenames/locations and preserve all prior versions, sources and the project index.
- Changed content/source/path/filename/ID/version or destination state requires fresh approval; no automatic version bump.
- Save evidence is recorded in the issue without editing frozen content after approval; release adds no files and removes no DRAFT markings.
- Client drafts contain no internal review links, private rates/margins, supplier terms or approval trails.
- Controlled evaluation creates no vault file and sends nothing.
