# Claims and Commitments Policy

Material statements include price, scope, performance, compliance, certification, schedule, availability, warranty, liability, confidentiality, intellectual property, acceptance and delivery.

For each material statement record:

- exact wording;
- source/revision;
- accountable reviewer;
- approval evidence;
- proposal location;
- any condition or limitation.

Do not strengthen source wording. For example, `designed to`, `target`, `estimate`, `expected`, and `subject to` must not become `will`, `guaranteed`, or `certified`.
