# Workflow - Pricing and Options

## Preconditions

- An approved client-safe selling-price reference exists.
- Currency, tax basis, validity, payment basis, and option relationship are explicit.
- The reference does not expose internal costing unless disclosure is specifically approved.

## Rules

- Transcribe approved totals and option values exactly.
- Do not derive price from cost, margin, markup, or discount rules.
- Do not apply a discount merely because it exists in a policy; require the exact approved scenario.
- Mark each option `included`, `additive`, `alternative`, or `excluded`.
- Show VAT/tax as included, excluded, reverse-charged, or pending review only when sourced.
- Do not present allowances as fixed prices or supplier quotes as client commitments.
- If validity has expired or input prices changed, set `PRICE_APPROVAL_REQUIRED`.

The internal review pack may cite the approved price-reference identifier but must not reproduce confidential cost build-up unnecessarily.
