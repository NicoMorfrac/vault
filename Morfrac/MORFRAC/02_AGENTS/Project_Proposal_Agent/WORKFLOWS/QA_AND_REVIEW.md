# Workflow - QA and Review

Run these checks before requesting save or release approval:

- proposal ID, version, client and project are consistent;
- all material claims have a source and accountable reviewer;
- scope, deliverables, exclusions, assumptions and client responsibilities agree;
- dates, durations, dependencies and milestone triggers agree;
- price totals, options, currency and tax wording match the approved price reference;
- no internal cost, margin, discount authority, supplier confidentiality, or unrelated project data leaked;
- terms use an approved reference or are visibly pending legal review;
- client and internal content are separated;
- placeholders and unresolved items are visible;
- previous-version changes are listed;
- spelling, numbering, cross-references and tables are coherent;
- no signature, send, acceptance or commitment action is implied.

Use `TEMPLATES/PROPOSAL_QA_CHECKLIST.md`. Any failed mandatory check blocks release readiness.
