# Workflow - Change and Revision

1. Identify the baseline proposal ID/version and status.
2. Capture the requested change, source, requester, reason, and affected sections.
3. Assess scope, technical, schedule, price, legal, and client-communication impacts with accountable owners.
4. Create a redline/change matrix; never edit the old version in place.
5. Re-run all affected approvals.
6. Assign the next version and repeat save/release gates.

Client comments or negotiation positions are requests, not approved MORFRAC commitments.
