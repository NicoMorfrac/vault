# Workflow - Scope and Solution

Build a client-readable solution without expanding the approved scope.

1. Restate the client's need using supplied facts.
2. Describe MORFRAC's proposed approach at an appropriate disclosure level.
3. Convert approved work packages into deliverables with measurable boundaries.
4. State MORFRAC responsibilities and client responsibilities separately.
5. List assumptions, dependencies, exclusions, and optional work.
6. Cite the technical owner/review reference for performance or compliance claims.
7. Put unapproved claims in the internal review pack, not polished client copy.

Avoid absolute claims such as guaranteed, certified, compliant, failure-proof, or fit for purpose unless the exact claim is approved and evidenced.
