# Workflow - Schedule and Delivery

Use only an owner-approved schedule reference.

For each milestone show:

- milestone/deliverable;
- target duration or date;
- start trigger;
- dependencies and client inputs;
- acceptance/review window;
- schedule owner and revision.

Distinguish duration from a committed calendar date. Mark lead times and external dependencies. Do not promise a delivery date when resources, supplier lead time, client data, or approvals are unresolved.

State how approved changes affect time and price.
