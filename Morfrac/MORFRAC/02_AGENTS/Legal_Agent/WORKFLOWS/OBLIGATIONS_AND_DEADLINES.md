# Workflow - Obligations and Deadlines

Extract obligations only from an identified executed/approved document or clearly labelled draft.

For each obligation record party, action, trigger, due rule/date, conditions, evidence, notice method/address, recurrence, dependency, consequence, owner, status and source clause/page.

For deadlines:

- identify triggering event and evidence date;
- quote the contractual/statutory rule and jurisdiction;
- state calendar/business-day rules, holidays, time zone, service method and inclusive/exclusive assumptions;
- show calculation steps;
- label counsel verification status.

Do not treat an extracted draft obligation as binding. Do not create calendar reminders or send notices without separate authorised workflow.
