# Workflow - Data Protection and Processing

1. Identify controller, joint-controller, processor, subprocessor, independent-controller or unknown roles from actual processing facts; do not decide by contract label alone.
2. Record purpose, duration, data categories, data-subject categories, lawful-basis owner, instructions, locations, transfers, subprocessors, security, retention/deletion, rights support, incident process, audits and return/deletion.
3. Check whether GDPR Article 28 or another required arrangement is triggered using current official sources.
4. Flag international transfers, special-category data, systematic monitoring, high-risk processing, employee data, children, biometrics or large-scale processing for specialist review.
5. Minimise personal data in drafts and issues.

The agent does not act as DPO, determine lawful basis, approve security measures, decide breach notification, or authorise transfers.
