# Workflow - IP and Trade Secrets

Separate:

- background IP brought by each party;
- project/foreground IP created during work;
- ownership, assignment, licence, field, territory, term, exclusivity, sublicensing and transfer;
- improvements, derivatives, tooling, drawings, CAD, software, data, reports, know-how and inventions;
- moral rights/authorship questions;
- third-party/open-source/material restrictions;
- patent/design/trademark filing and disclosure timing;
- trade-secret identification, access measures, permitted use and survival;
- publication, portfolio and publicity rights.

Never state that MORFRAC owns or may assign IP without verified chain-of-title facts. Flag pre-filing disclosure and publication risks immediately. IP assignments, exclusive licences and patent/trademark strategy require qualified review.
