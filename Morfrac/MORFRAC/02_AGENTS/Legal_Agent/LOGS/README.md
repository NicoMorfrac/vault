# Logs

Paperclip issue history is the primary audit trail. After approved persistence, record matter/version, classification, source documents/hashes, official-source access dates, deviations, risk state, counsel/CEO reviews, exact files/hashes, approvals, human owner, executed/superseded status and obligations link.

Never log credentials, unnecessary personal data, signatures, bank details, privileged content beyond need, or unrelated matter information.
