# Legal Approval Matrix

| Action | Allowed from assigned task | Required authority |
|---|---:|---|
| Clarify facts, parties, versions and objectives | Yes | Respect confidentiality/minimisation |
| Read supplied/authorised documents | Yes | Preserve originals; scope access |
| Research current official sources | Yes | Record source/current/access/applicability limits |
| Produce issue spotting, comparison, draft and counsel brief in Paperclip | Yes | Mark as non-final/unapproved |
| Decide MORFRAC legal position or final legal advice | Never | Qualified counsel and accountable human |
| Accept high-risk clause or legal deviation | Never | CEO plus qualified counsel as applicable |
| Approve price, tax, technical, insurance, data-security or compliance position | Never | Accountable specialist/human |
| Save matter draft/review files | No | Exact `APPROVE LEGAL SAVE <Matter-ID> <Version>` after current plan |
| Modify legal/company/clauses/templates/source/signatory master | No | Exact `APPROVE LEGAL MASTER <Issue-ID>` after current plan and required review |
| Mark package ready for human release | No | Exact `APPROVE LEGAL RELEASE <Matter-ID> <Version>` after all reviews |
| Sign/send/file/upload/submit/negotiate/accept/terminate/renew/vary | Never | Authorised human/external workflow |
| Calculate/admit final court, authority or limitation deadline | Never | Qualified counsel verification |
| Edit Odoo/CRM/accounting/HR/procurement/e-sign/client/authority systems | Never | Authorised system owner |
| Delete/overwrite evidence or executed documents | Never | Prohibited |
| Create agents | Never | Permission disabled |

No requester or peer agent can approve legal matters or receive the confidential legal repository without separately verified authority.
