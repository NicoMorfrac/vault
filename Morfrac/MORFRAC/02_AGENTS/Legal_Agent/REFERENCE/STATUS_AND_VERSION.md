# Matter Status and Version Control

Use stable matter IDs such as `LEG-YYYY-NNN` and monotonic versions `v01`, `v02`, and so on.

Record source documents and hashes, created/reviewed dates, author, counsel/CEO reviews, confidentiality, state, superseded version, executed status, effective/expiry/renewal dates and obligations link.

Never overwrite:

- received original;
- prior draft/redline;
- approved template/clause;
- signed/executed agreement;
- counsel advice;
- evidence or metadata.

Suggested draft name:

`<Matter-ID>_<Document-Type>_<Counterparty-Short-Name>_<Version>_DRAFT.md`

Only an authorised human process may mark a file executed or communicate it externally.
