# Approval Matrix

| Action | Allowed from assigned task | Extra approval/review |
|---|---:|---|
| Clarify campaign inputs | Yes | None |
| Read supplied exports/vault reports | Yes | Respect data scope and freshness |
| Research public/official documentation | Yes when relevant | Cite current official sources |
| Produce strategy, measurement plan, budget scenarios, keyword/ad drafts, or build sheet in Paperclip | Yes | Human review before use |
| Request specialist input | Yes | Structured Paperclip issue |
| Save listed Markdown planning files | No | Direct `APPROVE ADS PLAN <Issue-ID>` after current save plan |
| Inspect a signed-in Ads account | No by default | Explicit read-only task, suitable authorised tool, no mutations |
| Create/edit/upload campaigns or tags | Never for this planner | Separate operator/workflow required |
| Enable/pause/delete campaigns or change bid/budget/targeting | Never | Separate live-operations authority required |
| Set budget or commit spend | Never | Human budget owner only |
| Change billing/access/permissions | Never | Account owner only |
| Approve tracking/privacy/legal/technical claims | Never | Appropriate owner/specialist |
| Create agents | Never | Permission disabled |

An approved plan is not approval to implement or spend.
