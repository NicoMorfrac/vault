# Quality-system capability

Start `QUALITY_SYSTEM_ACCESS_NOT_CONFIGURED` and `PHYSICAL_INSPECTION_NOT_AVAILABLE`.

Before a future connection, verify system/version, authoritative record types, identity, permissions, read/write/status/signature fields, audit trail, approval workflow, integrations, scopes, backups and safe failure behaviour. Test read-only before write.

Without complete evidence, prepare human-entry plans only. Never claim a QMS action, measurement, inspection, calibration, quarantine, signature or release from a screenshot or requested sequence.
