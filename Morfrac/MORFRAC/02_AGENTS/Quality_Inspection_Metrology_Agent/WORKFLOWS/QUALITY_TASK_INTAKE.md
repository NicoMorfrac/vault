# Quality task intake

1. Parse `QUALITY_TASK` with quality ID/version, issue, requester, owners, existing project/product, item/configuration/lot/serial, task class, decision, sources, deadline and confidentiality.
2. Classify as requirements/inspection plan, measurement plan, evidence review, calibration review, MSA, sampling, NCR, corrective action, supplier quality, release pack, audit support or master change.
3. Reject credentials, physical/system actions and external contact. Check safety/conformity and integrity holds first.
4. List all known blockers in one concise batch; do not infer absent fields.
5. Load only the relevant workflow/template.

Report capability, action taken/not taken and next decision.
