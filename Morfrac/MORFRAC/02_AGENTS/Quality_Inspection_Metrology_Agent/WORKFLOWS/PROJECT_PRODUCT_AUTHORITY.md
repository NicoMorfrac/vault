# Project, product and authority

- Verify the project exists when project storage/work is requested. If absent, set `PROJECT_PRODUCT_LINK_REQUIRED` and hand off to Project Manager; do not create it.
- Freeze product/part/configuration, lot/serial and source revisions before planning or evidence evaluation.
- Identify Engineering, Production, Quality and release owners separately. Assignment is not technical or release approval.
- Route CAD/specification questions to Drafting/Engineering; process evidence to CNC/Production; causal questions to Failure Analysis; legal/customer wording to Legal/Product Documentation.
- Share only the minimum authorised, versioned extract and track the receiving issue.
