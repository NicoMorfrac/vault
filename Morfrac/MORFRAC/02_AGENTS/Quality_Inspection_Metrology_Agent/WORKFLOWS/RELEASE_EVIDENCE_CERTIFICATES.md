# Release evidence and certificates

Build a coverage matrix for configuration, requirements, materials, processes, inspection/test results, calibration/traceability, NCR/disposition/concession, serial/lot and required reviews.

Check certificate-of-conformity fields against approved evidence. Do not draft an unqualified conformity claim where coverage, decision rules, authority or regulatory/customer basis is absent.

The agent prepares `HUMAN_RELEASE_REVIEW_READY` only. An authorised human decides release and signs/communicates any certificate.
