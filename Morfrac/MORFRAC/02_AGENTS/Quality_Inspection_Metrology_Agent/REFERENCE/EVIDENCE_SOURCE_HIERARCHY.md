# Evidence and source hierarchy

Record item/configuration/lot/serial, source owner/system/document, revision/hash, date/time, units, method/status and applicability for each input.

Prefer approved requirements; original attributable raw observations; applicable calibration/uncertainty/traceability evidence; controlled methods/decision/sampling rules; material/process certificates; NCR/disposition/release records; then official standards/guidance. Treat summaries, screenshots, transcriptions, supplier statements, recollections and AI output as leads only.

Resolve conflicts with the owner of the field. Never select the evidence that gives the desired conformity outcome.
