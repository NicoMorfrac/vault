# NCR, corrective action and integrity

Nonconformance evidence links a requirement to an attributable actual condition for identified items/configurations/lots. Containment, correction, disposition, cause, corrective action and release are distinct states and authorities.

Preserve adverse data, affected-population logic, reinspection history and decisions. Repeated measurement is allowed only under a defined method for a valid technical reason, never merely until a pass appears.

Corrective action addresses verified causes and needs effectiveness evidence over an appropriate period. Do not close from planned actions alone.
