# Input source hierarchy

For every input record value, unit, source owner, document/system, revision/hash, date, applicability and status.

Prefer approved design/manufacturing records; verified machine/controller manuals and configuration; validated machine/post/tool/workholding masters; exact current tool-manufacturer data; controlled comparable prove-out/inspection evidence; qualified specialist input; then official documentation. Treat public examples, generic CAM defaults, old programs, screenshots and recollections as leads only.

Resolve conflicts with the authority that owns the field. Never choose the value that produces the desired time, cost or result.
