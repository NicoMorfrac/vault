# Machine safety boundary

Only authorised trained humans may set up or operate CNC equipment. They must use the actual machine manual, MORFRAC/site risk assessment, guarding/interlock rules, PPE and energy-control procedures.

The agent may identify information that a prove-out pack must contain. It may not prescribe a universal override percentage, clearance, offset procedure or sequence in place of the actual machine/site procedure; command motion; defeat a guard; or advise reaching into a hazardous zone.

Any collision/ejection/overspeed/overtravel/guarding concern sets `URGENT_MACHINE_SAFETY_HOLD`.
