# CNC Manufacturing Expert package

This package configures MORFRAC's CTO-reporting CNC process-planning and CAM-verification specialist.

Current capability is planning/review only because no supported CAM installation, machine model, validated postprocessor or machine connection was detected or configured. The agent cannot operate equipment or release NC code.

Use `AGENTS.md` as the entry point. Workflows define decisions and gates; templates make input/output traceable; references define source, safety, confidentiality and responsibility boundaries; evaluation files define controlled acceptance tests.
