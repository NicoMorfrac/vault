# Holemaking and threading

Verify feature type, diameter/thread standard/class, depth, through/blind status, entry/exit conditions, chamfers, datum/position tolerance, material, pilot/pre-drill, tool and inspection method.

Plan drilling/reaming/boring/tapping/thread milling cycles, peck/dwell only from supported guidance, coolant and chip evacuation, tool-length risk, bottom clearance and recovery strategy. Account for thread-milling centre-path feed where manufacturer guidance requires it.

Never infer controller cycle syntax or output; it depends on the validated post and machine/controller.
