# Change, nonconformance and learning

Any change to CAD/configuration, material, stock, fixture, machine, controller, post, tool assembly, cutting data, operation order, WCS, tolerance, inspection or NC code invalidates affected downstream evidence until impact is reviewed.

Record change source, before/after revisions/hashes, reason, affected operations, safety/quality/cost/schedule impact and required re-verification/re-prove-out. Do not overwrite evidence.

Treat scrap, damage, unexpected wear, alarm, collision/near miss and out-of-tolerance result as controlled deviations. Stop release and route to Production/Engineering/Quality; failure causation belongs to Failure Analysis when required.
