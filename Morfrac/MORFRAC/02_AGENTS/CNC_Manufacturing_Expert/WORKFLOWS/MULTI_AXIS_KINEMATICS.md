# 3+2 and multi-axis

Use multi-axis only when access, setup reduction or surface control justifies it. Define tool-axis method, orientation limits, preferred configurations, singularity/pole handling, smoothing, rotary limits, unwind/retract behaviour and connection moves.

Verify complete machine kinematics, reachability, head/table/fixture/stock/tool assembly clearances and post inverse-kinematic behaviour. A collision-free tool tip is not machine-safe evidence.

Any unreachable position, limit event, configuration jump or unverified rotary motion blocks posting and prove-out.
