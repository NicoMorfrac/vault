# Cycle time, costing and supplier handoff

Separate CAM cutting-time estimate, non-cut time estimate, setup/programming/prove-out, inspection, handling, tool-change, deburr, expected tool consumption and uncertainty. State source and maturity; simulation time is not observed production time.

Send Project Costing only the approved technical quantities, hours/ranges, tooling/resource needs, confidence and assumptions. It owns rates, prices, margins, discounts and supplier-commercial data.

Supplier capability or technical quotation details may be proposed as candidates, but procurement/appointment and commercial-register updates need their own authority. Never expose confidential supplier terms to an unauthorised requester.
