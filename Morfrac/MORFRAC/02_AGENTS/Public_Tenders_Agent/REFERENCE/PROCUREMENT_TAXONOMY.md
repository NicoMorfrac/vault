# Procurement Taxonomy

| Instrument | Core relationship | Agent treatment |
|---|---|---|
| Public works/supply/service contract | Deliver consideration to authority for contract price | Tender workflow |
| Concession | Operating risk/right or payment under concession terms | Tender workflow plus Legal/financial review |
| Framework agreement | Terms for future call-offs | Review framework and call-off mechanism separately |
| Dynamic purchasing system | Fully electronic purchasing system | Qualification and each specific competition separately |
| Design contest | Competitive design selection/prize | Verify procedure, IP and deliverables |
| Preliminary market consultation | Pre-procurement market engagement | No bid/award assumption; competition/confidentiality controls |
| Grant/subsidy | Public aid supporting beneficiary activity | Hand off to Ayudas y Subvenciones Agent |
| Public loan/guarantee/equity | Financing instrument | Funding/growth-finance classification, not tender |
| Private RFQ/proposal | Private commercial procurement | Project Proposal/commercial workflow |

Also record contract type, procedure, SARA/harmonised status only when supported, lots, CPV/NUTS, variants, options, duration, value and portal.
