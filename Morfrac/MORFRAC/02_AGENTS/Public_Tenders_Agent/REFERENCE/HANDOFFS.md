# Handoffs

| Need | Accountable destination | Minimum authorised handoff |
|---|---|---|
| Grant/subsidy/public-aid opportunity | Ayudas y Subvenciones Agent | Official source/ID/deadline and classification reason |
| Private client proposal | Project Proposal Agent | Approved task scope and client-safe tender-independent facts |
| Cost/price/cash scenarios | Project Costing Analyst plus CEO/accounting | Official price model, scope/quantities/terms; no unrelated bid strategy |
| Technical compliance/design/manufacturing | CTO/Engineering/CNC/Documentation as applicable | Exact clauses, deliverables, evidence request and deadline |
| Schedule/resources/project execution | Project Manager/CEO | Approved scope, milestones, capacity questions and dependencies |
| Legal/exclusions/terms/UTE/IP/data/challenge | Legal/qualified counsel | Exact clause, official source and decision needed; need-to-know only |
| Company/accounts/tax/Social Security/insurance | CEO/accounting/authorised owner | Exact evidence requirement and period; no raw unrelated records |
| Portal/signature/submission/authority contact | Authorised human representative | Final manifest, files/hashes, portal, deadline and receipt fields |
| Customs/shipping obligations | Customs & Shipping Documentation Agent | Awarded scope, routes/goods and authorised task extract |

Do not infer authority from an agent name. A handoff is not completion; retain the dependency until reviewed evidence returns.
