# Identifiers, Versioning and Storage

Use the authority's official procedure/notice and lot identifiers. If an internal ID is needed, use a stable format such as `TND-YYYY-NNN` linked to official IDs.

Version separately:

- opportunity/source capture;
- bid/no-bid pack;
- administrative, technical and economic bid components;
- human-submission manifest and receipt;
- award/formalisation pack;
- executed contract/obligation register/closeout.

Suggested states in filenames/headers: `DRAFT_NOT_SUBMITTED`, `SAVED_NOT_SUBMITTED`, `HUMAN_SUBMISSION_READY`, `SUBMITTED_BY_HUMAN_RECEIPT_REQUIRED`, `AWARD_NOT_ACCEPTED`, `EXECUTED_HUMAN_EVIDENCE`, `SUPERSEDED`.

Proposed repository after separate approval only:

`05_BUSINESS/Public_Tenders/`

- `00_MASTER/`
- `01_SEARCHES/`
- `02_OPPORTUNITIES/`
- `03_BIDS/`

Do not create it because it appears here. Preserve original official and submitted/executed evidence. Corrections create linked versions; never overwrite history.
