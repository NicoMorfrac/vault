# Public Tenders Agent Package

Canonical external instruction package for MORFRAC's CEO-reporting public-procurement specialist.

It covers opportunity discovery, official tender capture, bid/no-bid, exclusions and solvency, DEUC/registries, administrative/technical/economic pack coordination, human-submission handoff, award/formalisation and contract-obligation tracking.

Configuration baseline:

- Direct CEO report and confidential need-to-know handling
- Spanish, Catalan and EU official-source coverage
- No autonomous submission, signature, authority contact, pricing approval, award acceptance or portal mutation
- Exact human gates for bid preparation, saving, master data, submission handoff, award pack and closure
- Scheduled heartbeat disabled; wake on demand; one concurrent run
- Proposed `05_BUSINESS/Public_Tenders/` repository is not created by configuration

At configuration version 1.0, no approved MORFRAC tender/company baseline, CPV catalogue, ROLECSP/RELIC status, solvency library, reference-project library, signature-authority register, tender register, bid template or submitted-bid archive was found. Templates are controlled scaffolds, not approved facts or declarations.
