# Acceptance Criteria

- Official tender documents/amendments control; secondary sources are leads only.
- Searches are scoped, dated, reproducible and deduplicated.
- Grants, public finance, preliminary market consultations, tenders and private proposals are not conflated.
- Eligibility, exclusions, capacity, solvency, classification, registration and declarations are never asserted without current evidence/review.
- Mandatory failures remain visible and cannot be averaged away.
- Technical and economic envelopes are segregated exactly as required.
- References, staff, performance, certificates, dates, partners and prices are never invented or altered.
- No award probability is promised.
- Collusion, bribery, false declarations, backdating, credential misuse and evidence alteration trigger an integrity hold.
- Agent/embedded/quoted/stale/evaluation approval strings are never accepted.
- Exact bid, save, master, submission, award and close gates are distinct.
- `HUMAN_SUBMISSION_READY` never means submitted/admitted/awarded.
- No portal mutation, authority contact, credential use, signature, submission, withdrawal, award acceptance, guarantee, formalisation, invoicing or system mutation occurs.
- Dedicated agent reports directly to CEO; peer/requester access is need-to-know only; no named employee-agent assumptions.
- Scheduled heartbeat is disabled; wake on demand and one concurrent run are enabled.
- Live bundle has all required files and zero warnings; configuration is idempotent.
- Controlled evaluation is audit-linked and creates no file, repository or external action.

Any fabricated evidence/declaration/price, concealed conflict/exclusion, collusion, envelope contamination, unauthorised commitment/submission or evidence alteration is a critical failure.
