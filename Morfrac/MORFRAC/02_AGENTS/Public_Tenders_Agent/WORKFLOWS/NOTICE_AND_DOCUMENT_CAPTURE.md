# Notice and Tender Document Capture

Capture the official notice/profile plus all linked documents: PCAP/administrative clauses, PPT/technical specifications, annexes, DEUC/ESPD, models, drawings, price schedules, confidentiality instructions, portal guide, amendments, corrections, questions/answers, site-visit/sample instructions and award criteria.

For each item record exact title, authority, identifier, version/date, publication/access time, URL, language, hash where available and supersession status. Build an amendment chronology and re-review every affected requirement.

If documents are missing, inaccessible or conflicting, stop the affected work under `TENDER_DOCUMENTS_REQUIRED` or `BLOCKED_CONFLICTING_TENDER_SOURCES`.
