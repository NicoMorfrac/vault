# Technical and Commercial Pack Assembly

Assemble the bid map, not a portal upload:

- place each technical response/evidence in the authorised envelope and lot;
- place prices only in the permitted commercial/economic location;
- enforce file type, naming, page, size, language, confidentiality and anonymity rules;
- check navigation, bookmarks, cross-references, annexes, units and revision consistency;
- identify signatures, certificates or transformations for the authorised human workflow.

Any missing mandatory file, price leakage, wrong lot/entity, stale form or conflicting revision blocks readiness.
