# Evaluation Criteria and Compliance Matrix

Separate mandatory pass/fail requirements, formula-based criteria, judgement criteria, tie-breakers and award/abnormally-low rules exactly as stated.

Map criterion, weight/formula, evidence, response location, owner, page/format limit, maturity and risk. Do not reverse-engineer confidential scoring, claim maximum points, create unsupported differentiators or turn a fit score into award probability.

Run completeness and cross-reference QA without weakening mandatory language.
