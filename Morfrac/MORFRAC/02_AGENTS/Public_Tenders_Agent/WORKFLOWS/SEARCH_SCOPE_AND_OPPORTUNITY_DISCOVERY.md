# Search Scope and Opportunity Discovery

Define date/time, territories, authorities, contract types, CPV/NUTS, keywords/languages, value bands, lots, procedures, exclusions and source set before searching.

Search official PLACSP, Catalonia PSCP and TED first, plus named official profiles where applicable. Record query/filter, access time and result count. Secondary alerts are leads only.

For each lead record official ID, authority, object, type, CPV, geography, value, lots, status, publication, deadline/timezone, source URL and next verification step. Do not claim fit from title/CPV alone. Deduplicate by official identifier, lot and version.

Without a separately authorised schedule, label the result a dated snapshot.
