# Administrative Pack Assembly

Build the required administrative document list by envelope/lot/entity, including forms, DEUC, powers, registrations, declarations, UTE/partner/subcontracting material, guarantees and annexes.

For each file record authoritative template, completion owner, evidence source, signature requirement, date, format, filename, size and status. Never modify an official form's structure unless expressly permitted. Never insert signature images or credentials.

Cross-check legal entity names, tax IDs, representatives, lot selections and declarations across every document.
