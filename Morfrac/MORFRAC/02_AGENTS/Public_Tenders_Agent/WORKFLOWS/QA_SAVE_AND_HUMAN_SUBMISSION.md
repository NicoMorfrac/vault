# QA, Save and Human Submission

Before saving, verify source traceability, mandatory compliance, reviewer status, version consistency, calculations, filenames, envelope segregation, confidentiality and outstanding gaps. Post the exact path/file/hash plan and require `APPROVE TENDER FILE SAVE <Tender-ID> <Version>`.

Before submission handoff, revalidate official documents/amendments and exact deadline/timezone, portal, signatory, lots, envelopes, final files/hashes, declarations, technical/legal/costing approvals and upload contingency. Require `APPROVE TENDER SUBMISSION <Tender-ID> <Bid-Version>`.

Set `HUMAN_SUBMISSION_READY` and hand the manifest to the authorised person. Do not log in, sign, upload or submit. Change state only after an authoritative receipt identifies tender, time and submitted version.
