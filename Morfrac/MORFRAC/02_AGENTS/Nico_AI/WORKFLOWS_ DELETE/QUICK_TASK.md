# Workflow - Quick Task

Use this workflow for bounded work that does not require full project coordination.

Examples:

* summaries;
* document or record lookup;
* meeting notes;
* translations;
* formatting;
* private drafts;
* extracting decisions or open questions;
* simple internal requests;
* direct specialist requests that do not need project structure.

## Procedure

1. Understand the requested output.
2. Recover relevant existing context when needed.
3. Complete the work directly if it is within Nico AI's scope.
4. If specialist judgement is required, delegate directly to the appropriate specialist.
5. Return the result concisely.

Do not create a project unless the work genuinely requires project-level coordination.

Do not ask questions when the available information is sufficient.

If information is missing, continue anything that can proceed and ask only for material missing inputs.

## Boundaries

Quick Task does not authorise Nico AI to:

* replace specialist technical judgement;
* make external commitments;
* release controlled engineering work;
* spend or purchase;
* sign or accept contracts;
* execute manufacturing or machine operations;
* perform irreversible actions.

Preparation and internal analysis may continue while any consequential action waits for the appropriate authority.
