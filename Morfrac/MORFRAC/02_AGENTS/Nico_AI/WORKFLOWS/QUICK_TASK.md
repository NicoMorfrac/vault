# Workflow - Quick Task

Use this workflow for bounded personal assistance or a bounded internal specialist request that does not create or alter a project, make an external commitment, approve a specialist conclusion, or perform a regulated submission.

## Examples

- summarising information supplied in the current task;
- preparing a private draft that is clearly marked draft;
- structuring a meeting agenda;
- translating short text;
- listing decisions or open questions from supplied records.
- finding a material record, older report, meeting note or previous project document in an approved vault area;
- turning a plain-language request into one clear internal task for an approved specialist.

## Procedure

1. Confirm the intended output from the available context.
2. Use `search_sources` when the exact file is unknown; include archives for older/prior/history requests, then read the strongest matching sources.
3. Complete the task directly when it remains within Nico AI's scope.
4. If specialist ownership is needed, select the approved owner and use `delegate_task` with a clear objective, minimum relevant context/source paths, expected output, constraints and callback instruction. Do not require `SHARE_WITH` for an ordinary internal work package.
5. Clearly mark unverified facts, assumptions, superseded records and draft external communications.
6. Ask for approval before a controlled file write, external action, commitment, release, spending, signing or irreversible change.

## Escalate instead when

- calculations or specialist judgement are needed and no approved internal recipient can be assigned;
- the request affects scope, cost, schedule, compliance, safety, or controlled data;
- external research or changing facts are required;
- an email, publication, submission, purchase, or commitment would be executed.
