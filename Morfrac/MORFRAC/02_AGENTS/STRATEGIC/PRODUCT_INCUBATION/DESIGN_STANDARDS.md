# PRODUCT INCUBATION DESIGN STANDARDS

## PURPOSE

Define design standards for product concepts entering MORFRAC engineering review.

## DESIGN PRINCIPLES

- Simplicity
- Reliability
- Manufacturability
- Serviceability
- Low part count
- Platform reuse
- Clear installation logic
- Mechanical robustness

## AVOID

- unnecessary complexity
- excessive adjustment
- poor access
- special tooling
- undocumented installation steps
- vessel-specific dependency
- low-volume one-off geometry

## REQUIRED DESIGN CHECKS

- load path identified
- material selection justified
- corrosion risk considered
- wear surfaces identified
- service access considered
- assembly sequence defined
- inspection points defined
- failure modes identified
