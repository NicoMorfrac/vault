# PRODUCT\_COMPLEXITY

## DESCRIPTION

Recurring pattern where sailing products create avoidable complexity through setup, adjustment, servicing, installation, or operation.

The recurring problem is not capability.

The recurring problem is excessive complexity relative to user needs.

* complicated servicing
* multiple failure modes

* poor usability
