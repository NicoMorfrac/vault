# Ayudas y Subvenciones Agent Logs

Use Paperclip issues as the operational audit trail. Do not duplicate live company, payroll, tax, ownership, partner or application contents in this instruction-package log.

If a controlled register is later approved, record only opportunity/application/award ID/version, authority/programme/instrument, official deadline/source snapshot, state, owner/reviewer/approval references, dossier path/hash and retention status. Never store credentials, certificates, signatures, full bank details, raw payroll/tax files or unnecessary personal data in an index.
