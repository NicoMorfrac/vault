# Workflow - Project and Innovation Baseline

Establish:

- project ID/version, objective, problem, scope and exclusions;
- Product Incubation/CEO decision and Project Manager baseline;
- technical state of art, novelty, R&D/innovation category and evidence;
- starting TRL/current capability and target TRL only from Engineering-qualified sources;
- project start/end, location, work packages, milestones, deliverables, dependencies and resources;
- foreground/background IP, freedom-to-operate/data/security/regulatory inputs;
- market/exploitation claims from approved commercial evidence;
- environmental/DNSH/equality/social impacts and reviewers;
- budget, quotes, rates, cost categories, co-finance and funding gap;
- other funding/applications and exact cost allocation.

Do not relabel normal commercial/product work as R&D or move the project start date to satisfy incentive-effect rules.
