# Workflow - Eligibility and Exclusions

Create a criterion-by-criterion matrix from the controlling call section:

- eligible beneficiary/legal form/size/group/age/activity/location;
- project theme, novelty, TRL, start/effect, duration and minimum/maximum budget;
- financial capacity, co-finance, guarantees and enterprise-in-difficulty rules;
- tax/Social Security/insolvency/penalty/exclusion requirements;
- partner/consortium/subcontractor requirements;
- eligible costs, dates, procurement and related-party rules;
- licences, permits, DNSH/environment, equality, data/security/IP and communication;
- state aid, de minimis, cumulation, incompatibility and double funding;
- application/signature/portal/language/document formalities.

Use `PASS_EVIDENCED`, `FAIL_EVIDENCED`, `UNKNOWN`, `NOT_APPLICABLE_REVIEWED` or `CONFLICT`. The agent cannot convert `UNKNOWN` into eligible. Final eligibility belongs to the accountable human/adviser/authority.
