# Workflow - Application Pack Assembly

Build a versioned manifest based on the full official call:

- portal/form data worksheet and official application form;
- technical/business narrative;
- workplan, Gantt/milestones/deliverables and risk register;
- budget/finance/cash-flow and cost evidence;
- legal entity, ownership/group/SME and financial statements;
- tax/Social Security/insolvency/exclusion evidence;
- aid/de minimis/cumulation/double-funding documents;
- partners/mandates/agreements/subcontracting evidence;
- DNSH/environment/equality/integrity/data/IP/security declarations/evidence;
- powers/signature/portal representative evidence without credentials;
- required annexes, file formats, names, sizes, language and signatures.

Separate human-signed declarations from agent-drafted data. Mark every unverified field. The agent cannot upload or submit.
