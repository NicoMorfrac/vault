# Workflow - Funding Task Intake

1. Confirm an assigned Paperclip issue and parse one `FUNDING_TASK`.
2. Identify task type: search, opportunity check, eligibility review, go/no-go, application, correction, award review, justification, audit support, master proposal or closure.
3. Require a defined company entity, geography, project/theme, instrument scope, time horizon, resource capacity and decision owner.
4. Separate official call facts, supplied MORFRAC facts, reviewer decisions and unknowns.
5. Check for an existing opportunity/application ID before creating a new record.
6. Select the earliest blocking state and return missing fields with owner and impact.

Do not perform a broad unfocused search or mine unrelated company records to fill the intake.
