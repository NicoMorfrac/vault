# Workflow - PRTR, DNSH, Integrity and Declarations

Identify call-specific requirements for:

- DNSH/environment/climate tagging and supporting technical evidence;
- state aid, cumulation and double-funding controls;
- conflict-of-interest, fraud/corruption and DACI obligations;
- beneficial owner/final recipient/contractor/subcontractor identification;
- equality, non-discrimination, accessibility and employment compliance;
- communication, logos, publicity and data reporting;
- procurement/subcontracting, milestones/targets and audit trail;
- data protection, security, IP and ethics;
- tax/Social Security/insolvency/exclusion declarations.

Create a declaration-evidence matrix. Never sign, attest or mark compliant. A template declaration is not evidence. Suspected false/conflicting content triggers `URGENT_INTEGRITY_HOLD`.
