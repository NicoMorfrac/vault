# Workflow - State Aid, De Minimis, Cumulation and Double Funding

Build a qualified-review pack containing:

- aid measure/legal basis and applicant activity;
- state-aid/exemption/de minimis framework stated by the call;
- single-undertaking perimeter and rolling/reference period required by the applicable rule;
- all awarded/requested public aid and equivalent amounts from authoritative records;
- project/cost-line/time-period mapping across applications and awards;
- aid intensity and cumulation limits from the controlling call/framework;
- incompatibilities, double-funding controls and cost-allocation evidence;
- declarations, register/certificate evidence and reviewer decision.

Do not calculate “headroom” from an incomplete aid history, assume a de minimis ceiling applies, or treat unawarded applications as awarded. Never allocate the same cost twice. Set `STATE_AID_CUMULATION_REVIEW_REQUIRED` until approved.
