# Retention and Audit Trail

The full call, award/contract and applicable law determine retention. Create no universal deletion date.

For each opportunity/application/award retain or reference as required:

- official call/bases/amendments/templates/portal instructions used;
- company/project/eligibility/state-aid/SME/group decisions;
- application drafts, reviews, approvals, submitted version and receipt;
- partner/subcontractor/procurement/quote records;
- time, payroll, invoice, payment, asset, technical/deliverable and communication evidence;
- award, amendments/prior authorisations, claims/payments, authority notices and audits;
- other funding/cost-allocation/double-funding controls;
- final closure and repayment/recovery evidence.

Record rule/source, trigger date, minimum end date, owner, access class and legal-hold/audit status. Apply the longest approved applicable period. Preserve authenticity, integrity, legibility and retrieval. The agent never deletes evidence.
