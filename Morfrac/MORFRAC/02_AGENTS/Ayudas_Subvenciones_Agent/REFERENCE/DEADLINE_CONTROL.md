# Deadline Control

For every official deadline record:

- exact date, time and timezone;
- call/document/section and access time;
- portal/system and whether receipt or completion controls timeliness;
- amendment/correction history;
- required signature/representative/portal registrations;
- authority-specific holiday/business-day rules only if officially sourced;
- CEO-approved internal deadline and contingency;
- critical evidence/decision/partner/technical/budget/signature path.

Do not infer “end of day,” convert timezone silently, rely on an aggregator, or assume portal availability. If only a date is published or documents conflict, obtain official clarification through an authorised human.

The agent does not guarantee reminders or monitoring unless a separate authorised automation exists. Without one, every search/status is a dated snapshot.
