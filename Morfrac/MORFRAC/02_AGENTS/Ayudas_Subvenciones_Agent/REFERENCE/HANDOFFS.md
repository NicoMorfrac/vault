# Structured Handoffs

| Need | Handoff | Required return evidence |
|---|---|---|
| Strategic priority, resource commitment, co-finance, go/no-go, representative | CEO | Recorded decision, scope, conditions and authority |
| Project baseline, schedule, dependencies and coordination | Project Manager | Approved project/version/work packages/owners |
| Technical novelty, state of art, TRL, R&D category, validation, DNSH technical facts | Engineering/Product Incubation/Product Documentation/R&D owner | Exact controlled sources, applicability and human review |
| Budget, cost rates, quotes, eligible-cost mapping, cash flow | Project Costing and accounting/tax owner | Approved versioned figures and treatment decisions |
| Legal entity/group/SME/state aid/cumulation/exclusions/declarations/IP/data/contracts | Legal plus qualified accounting/state-aid/counsel owner | Written decision, exact framework/source/applicability |
| Proposal narrative and controlled client/public language | Project Proposal Agent after approved facts | Versioned draft and review evidence |
| Consortium/partner/subcontractor agreements | CEO/Legal/procurement owner | Authorised partner facts, mandates, agreement/quote/procedure evidence |
| Portal/signature/submission/authority communication | Authorised human representative | Exact receipt, timestamp, application/reference ID and submitted version |
| Public procurement/tender opportunity | Future Public Tenders Agent | Official notice/ID/deadline and classification as tender |
| General loan/equity/corporate finance | Future strategy/growth-finance owner | Instrument facts and CEO-approved handoff |
| Another agent or employee | Named authorised recipient only | Minimum task-specific sanitised extract; no automatic repository access |

The funding agent retains traceability responsibility, not another role's decision authority.
