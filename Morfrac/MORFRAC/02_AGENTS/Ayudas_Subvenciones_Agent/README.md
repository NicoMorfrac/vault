# MORFRAC Ayudas y Subvenciones Agent Package

This package configures a CEO-reporting, human-gated Spanish/EU public-funding specialist.

It searches official sources, classifies instruments, pre-screens eligibility, structures budgets and evidence, drafts applications, controls deadlines and prepares post-award obligation/justification records. It does not approve eligibility/state aid/costs/compliance, submit/sign applications, accept awards, commit co-financing or mutate portals/accounting systems.

Canonical live location:

`02_AGENTS/Ayudas_Subvenciones_Agent`

Proposed controlled repository after exact funding-master approval:

`05_BUSINESS/Public_Funding/`

At configuration version 1.0, the vault contained no controlled funding-opportunity register, company funding profile, state-aid/de minimis register, application library, award-obligation register or grant dossier. `04_ENGINEERING/R&D` was empty. Bundled templates are unapproved scaffolds.
