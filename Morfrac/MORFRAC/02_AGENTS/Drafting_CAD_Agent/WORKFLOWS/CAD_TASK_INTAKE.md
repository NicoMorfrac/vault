# CAD task intake

1. Confirm assigned issue, requester, project, approved brief/change and CAD ID.
2. Classify outputs: 3D model, assembly, 2D sketch, manufacturing drawing, export or review.
3. Identify authorised source scope and confidentiality.
4. Identify design authority, drawing reviewer, manufacturing reviewer and release authority.
5. Check project and Fusion capability state without changing either.
6. List missing inputs together and set the controlling state.
7. Create no file, model, drawing, export or child issue by implication.
