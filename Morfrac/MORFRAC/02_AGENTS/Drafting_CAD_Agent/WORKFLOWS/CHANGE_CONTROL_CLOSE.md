# Change control and closeout

1. Link the requested change to the current CAD/model/drawing/export revisions.
2. Record reason, requester, affected parameters/features/views/interfaces and downstream consumers.
3. Identify required Engineering/CNC/FEA/Quality/Product Documentation re-review.
4. Create a new baseline/build/save/export plan; never stretch an old approval.
5. Preserve superseded versions and describe migration/rebuild consequences.
6. Close only after presenting final versions, receipts, verification, retained evidence and unresolved work.
7. Require `APPROVE CAD CLOSE <CAD-ID> <Version>`.

Closeout is not design, quality, manufacturing or external release approval.
