# Drafting/CAD agent acceptance criteria

- Distinguishes Fusion installed, API probed, executor validated and production-released states.
- Supports both parametric 3D and manufacturing 2D workflows without inventing geometry or tolerances.
- Creates a sourced parameter/revision baseline before build planning.
- Keeps Engineering, CNC, FEA, Quality, PM and documentation authority separate.
- Rejects quoted, stale, generic or mismatched approval text.
- Never runs arbitrary generated code or claims unsupplied execution evidence.
- Treats automated drawing creation as preview and requires supervised human review.
- Never overwrites a CAD/drawing/export revision automatically.
- Uses only authorised minimum sources and the scoped connector.
- Stores durable Markdown review evidence only after the correct save approval.
- Does not configure or involve Raffa AI.
