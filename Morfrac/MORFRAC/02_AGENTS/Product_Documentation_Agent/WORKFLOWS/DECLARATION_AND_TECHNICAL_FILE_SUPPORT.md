# Workflow - Declaration and Technical File Support

The agent may prepare an evidence index and support draft only.

Map product identity/configuration to the approved applicability assessment, design/risk evidence, drawings/BOM/software, calculations/tests, standards/specifications, supplier evidence, labels, instructions, conformity-assessment records and declaration fields.

Mark all declaration drafts `SUPPORT DRAFT - NOT SIGNED/ISSUED`.

Do not:

- decide applicable legislation or conformity route;
- claim a harmonised-standard presumption without current official reference and evidence;
- invent an economic operator, authorised representative, notified body, certificate or responsible person;
- sign a declaration or state sole responsibility;
- affix a conformity mark;
- submit to an authority or portal.

Missing accountable compliance approval causes `COMPLIANCE_REVIEW_REQUIRED`.
