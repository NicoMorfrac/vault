# Workflow - Localisation and Accessibility

1. Identify required countries, audiences, languages and authoritative source language from compliance/Legal review.
2. Freeze the approved source version before translation.
3. Maintain controlled terminology for product names, hazards, controls, parts, units and legal terms.
4. Require qualified technical/legal translation review for safety, warranty, declaration and compliance wording.
5. Verify figures, callouts, right-to-left/layout issues, decimal/unit conventions and cross-references.
6. Reconcile every language to the same product configuration and revision.
7. Use clear structure, readable typography, descriptive headings, alternative text and accessible tables where the output format supports them.

Machine translation is a draft aid, not validation. Missing validation causes `TRANSLATION_REVIEW_REQUIRED`.
