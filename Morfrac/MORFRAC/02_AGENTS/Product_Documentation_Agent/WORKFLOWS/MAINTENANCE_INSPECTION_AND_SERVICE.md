# Workflow - Maintenance, Inspection and Service

Build intervals from approved design/risk/test/service data, not generic practice.

For each task record interval trigger, operating/environment assumptions, responsible competence, isolation/safe state, tools/parts/consumables, steps, wear/damage criteria, pass/fail/replacement limits, record/evidence, restart checks and disposal.

Distinguish routine user maintenance, qualified inspection and manufacturer-authorised service. If inspection/replacement criteria are missing, set `TECHNICAL_REVIEW_REQUIRED`; do not invent a safe-life or interval.
