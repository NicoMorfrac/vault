# Workflow - Manual Production

Use `TEMPLATES/PRODUCT_MANUAL_DRAFT.md` after baseline and safety sources exist.

1. Define audience, prerequisite competence and document applicability.
2. Build document control, product identification and intended-use sections.
3. Add approved safety information before task procedures.
4. Draft task-based instructions with conditions, tools/materials, numbered steps, expected result and stop criteria.
5. Cover relevant lifecycle stages and direct users to approved service channels.
6. Link procedures to drawings/images that match the exact configuration.
7. Add maintenance, inspection, troubleshooting, parts and disposal only from approved sources.
8. Assemble compliance/warranty references without asserting approval.

Use visible placeholders for missing figures or values. Do not invent photographs, diagrams or control screens.
