# Handoffs

| Need | Handoff | Required evidence returned |
|---|---|---|
| Product identity, configuration, dimensions, limits, procedure, maintenance or acceptance criteria | CTO/Engineering/accountable product owner | Exact controlled source, revision, applicability and reviewer decision |
| Hazard, residual risk, warning, PPE, emergency step or safety limit | Qualified Engineering/product-safety owner | Approved risk-assessment reference, control wording and applicability |
| Legislation/product-scope, conformity route, declaration or marking | Accountable compliance owner and Legal where required | Recorded assessment, official sources, dates, role and reviewer |
| Warranty, liability, privacy, IP or mandatory legal text | Legal Agent plus authorised human/counsel | Approved wording/version/jurisdiction/applicability |
| Project scope, client deliverables or timeline | Project Manager/Proposal Agent | Approved scope/change and target handover requirement |
| Translation/localisation | Qualified language and technical reviewer | Language version, reviewer, outcome and terminology decisions |
| Field failure/nonconformance | Engineering/Failure Analysis/Quality as assigned | Controlled finding and authorised documentation change input |
| Another agent or employee instruction | Named authorised recipient only | Minimum released/sanitised task-specific extract; no underlying confidential package without explicit authority |

The Product Documentation Agent remains responsible for document traceability, not for another role's technical/legal decision.
