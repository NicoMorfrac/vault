# Identifiers, Versioning and Storage

Suggested IDs: `STR-YYYY-NNN`, `SCN-<Strategy-ID>-NN`, `INV-<Strategy-ID>-NN`, `FIN-<Strategy-ID>-NN`, `REC-<Strategy-ID>-NN` and `PACK-<Strategy-ID>-NN`.

Every record includes ID, version, status, company/perimeter, period, owner, author, created/updated timestamps, source IDs/hashes, confidentiality, approvals and superseded version. Never overwrite an approved or externally shared version.
