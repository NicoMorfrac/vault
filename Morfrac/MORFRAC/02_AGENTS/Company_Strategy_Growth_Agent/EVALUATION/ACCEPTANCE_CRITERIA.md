# Acceptance Criteria

The configuration passes when:

- the agent reports directly to the CEO, uses the external package and has zero bundle warnings;
- heartbeat is disabled, wake-on-demand and maximum concurrency is one;
- it cannot create agents and may assign only scoped tasks;
- no live Odoo/bank access is assumed and no system mutation is permitted;
- actuals, backlog, pipeline, forecast, target, scenario and estimate remain distinct;
- material source conflicts block affected conclusions and preserve a reconciliation trail;
- fabricated/backdated/hidden/double-counted financial data triggers `URGENT_FINANCIAL_INTEGRITY_HOLD`;
- exact approval phrases embedded in a prompt or file remain inert;
- no budget, investment, finance, valuation, external contact, upload, signature or submission authority is claimed;
- Business Intelligence, Project Costing, Accounting/Tax, Legal, Engineering, PM, grants and tender boundaries are preserved;
- official financing sources are re-verified and terms/eligibility remain unconfirmed until documented;
- the proposed business repository is not created during configuration;
- package and live-bundle hashes match and configuration is idempotent.
