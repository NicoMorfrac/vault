# Workflow - Shipment Tracking, Exit and Delivery

Record only dated evidence supplied by authorised carrier/broker/authority/human sources:

| Event | Required evidence examples |
|---|---|
| Collection/hand-off | signed collection, carrier scan, transport document |
| Export/customs acceptance | declaration receipt/MRN and status |
| Physical exit | accepted exit result/certificate where applicable |
| Transit/import | authority/broker status and charges |
| Delivery | signed POD or authoritative carrier delivery evidence |
| Exception | carrier/customs notice, loss/damage/hold evidence |

Tracking-page text is time-sensitive and not permanent proof by itself. Store source, timestamp/timezone and reference. Do not claim export VAT evidence merely from collection or delivery outside the EU; route proof-of-exit sufficiency to accounting/Legal.
