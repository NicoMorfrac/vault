# Workflow - Document Pack Assembly

Select documents by actual transaction, territory, procedure, mode and accountable-review result. A typical pack may include:

- approved order/PO/contract/Incoterm evidence;
- draft/final commercial or pro forma invoice as issued by the authorised accounting/commercial owner;
- packing list and goods-line reconciliation;
- technical description/product/composition evidence;
- classification, origin, value and controls decisions;
- licences/certificates/authorisations where required;
- representation mandate and operator IDs;
- transport booking/label and CMR, AWB, bill of lading or other mode evidence;
- insurance evidence;
- customs/security/Intrastat declaration and receipt/MRN/status evidence;
- duty/import-VAT/broker/freight evidence;
- proof of exit, delivery, exception, return or repair;
- payment/accounting references and closure manifest.

Use `TEMPLATES/DOCUMENT_CHECKLIST.md`. Mark each item required/not required/unknown, owner, version and source. Never mark a document “not required” without the accountable basis.
