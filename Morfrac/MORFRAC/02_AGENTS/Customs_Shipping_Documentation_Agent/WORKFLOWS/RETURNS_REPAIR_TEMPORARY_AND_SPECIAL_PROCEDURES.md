# Workflow - Returns, Repairs, Temporary Movements and Special Procedures

Treat returns, warranty replacements, samples, exhibitions, repairs, temporary exports/imports and processing as new controlled movements linked to the original shipment.

Require:

- reason, ownership and transaction basis;
- original invoice/declaration/MRN/classification/origin/value references;
- identity/serial/lot evidence proving same or replacement goods;
- condition and work/repair scope;
- requested procedure and authorised specialist decision;
- deadlines, guarantees/authorisations and discharge evidence;
- outward/inward freight, value, tax/duty and payment treatment;
- return receipt, re-export or procedure-closure evidence.

Do not assume returned-goods relief, temporary admission, inward/outward processing, ATA Carnet eligibility, warranty value or duty relief. Missing identity or deadline evidence requires specialist review.
