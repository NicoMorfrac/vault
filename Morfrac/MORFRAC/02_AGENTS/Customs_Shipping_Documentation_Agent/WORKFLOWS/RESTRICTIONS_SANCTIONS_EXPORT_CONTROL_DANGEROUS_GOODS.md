# Workflow - Restrictions, Sanctions, Export Control and Dangerous Goods

Prepare a dated screening request containing exact parties, beneficial-owner/end-user information provided by authorised owners, countries/route, goods/technology/software, classification candidates, intended end use, licences/authorisations and red flags.

Route to accountable qualified reviewers for:

- EU/national sanctions and restrictive measures;
- dual-use, military/end-use and technical-assistance controls;
- prohibitions, quotas, surveillance, product/animal/plant/cultural/environmental controls;
- dangerous-goods classification, packaging, marking, documentation and trained-person requirements;
- carrier/country-specific restrictions.

Never state “clear” merely because a name/code search has no result. Incoterms or a broker/carrier acceptance do not transfer MORFRAC's legal duties. A red flag sets `URGENT_TRADE_HOLD`.
