# Workflow - Classification and TARIC Review

1. Obtain exact goods facts and the accountable classification owner.
2. Record existing approved CN/HS/TARIC code, jurisdiction, effective date, decision/source and product/configuration applicability.
3. If absent, research only a clearly labelled candidate using current official nomenclature/TARIC and relevant explanatory/legal material available to authorised reviewers.
4. Record candidate rationale, alternatives, missing facts, measures/conditions shown on the dated query and whether BTI review is needed.
5. Require qualified customs approval before using a code in a human submission pack.

TARIC is dynamic. A historic code or supplier/customer code is evidence, not approval. The agent cannot apply for, interpret as counsel, or claim a BTI.
