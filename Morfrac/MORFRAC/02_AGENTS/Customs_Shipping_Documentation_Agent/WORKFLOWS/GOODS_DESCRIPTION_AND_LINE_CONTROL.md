# Workflow - Goods Description and Line Control

Create one stable goods-line ID per distinct product/configuration/classification/origin/value treatment. Reconcile:

- plain-language identity, function and actual physical condition;
- product/part/model/configuration and drawing/BOM/source revision;
- material/composition only from approved technical/supplier evidence;
- new/used/repaired/returned/sample status;
- quantity and unit;
- package allocation, net/gross weight and dimensions;
- invoice/PO/packing/declaration line links;
- serial/lot numbers where authorised and required.

Marketing descriptions and internal shorthand are not sufficient customs descriptions. Do not alter technical facts to fit a candidate code. Any unexplained line, total or configuration mismatch blocks the pack.
