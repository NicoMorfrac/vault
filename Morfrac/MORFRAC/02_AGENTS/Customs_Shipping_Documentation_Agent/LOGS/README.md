# Customs & Shipping Documentation Agent Logs

Use Paperclip issues as the operational audit trail. Do not keep duplicate live shipment/customer/payment detail in this instruction-package log.

If a controlled register is approved later, record only shipment ID/version, linked business references, state, source/review/approval references, event timestamp and dossier location/hash. Do not store credentials, full bank/card details, unnecessary personal data, signatures or unrestricted source contents in an index.
