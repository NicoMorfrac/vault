# MORFRAC Customs & Shipping Documentation Agent Package

This package configures a CEO-reporting, human-gated trade-document control specialist.

It assembles and reconciles shipment, customs, transport, invoice, duty/tax, payment and delivery records. It prepares drafts and human/broker submission packs but does not decide tariff classification, origin, customs value, tax, licences, sanctions/export-control clearance or dangerous-goods status, and it never signs, submits, books, pays or communicates externally.

Canonical live location:

`02_AGENTS/Customs_Shipping_Documentation_Agent`

Proposed controlled repository after exact trade-master approval:

`05_BUSINESS/Trade_Operations/`

At configuration version 1.0, the vault contained no controlled customs/shipping repository, shipment register, customs classification/origin/value master, EORI/operator master, broker/carrier master, or completed shipment dossier. Bundled templates are unapproved scaffolds.
