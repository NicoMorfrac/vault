# Retention Baseline

Retention is assigned per record class by Legal/accounting/customs owners. Do not apply one generic deletion date.

Official starting points checked 2026-08-30:

- Union Customs Code Article 51 requires customs documentation/information to be kept for at least three years, with different period start points and possible extension. Source: https://eur-lex.europa.eu/eli/reg/2013/952/oj
- AEAT states invoices and tax-related supporting evidence are generally retained for the four-year tax limitation period, with exceptions that can extend it. Source: https://sede.agenciatributaria.gob.es/Sede/iva/facturacion-registro/facturacion-iva/obligacion-conservar-facturas.html
- AEAT notes Spanish commercial books, correspondence and business supporting documentation generally have a six-year preservation period from the last entry, while tax review/effect periods can differ or extend. Source: https://sede.agenciatributaria.gob.es/Sede/impuesto-sobre-sociedades/gestion-impuesto-sobre-sociedades/obligaciones-contables-registrales/conservacion-libros.html

## Control rule

For each dossier record:

- identify customs/tax/commercial/contract/product/liability/licence/insurance/data-protection categories;
- record source rule, trigger/start date, minimum end date, accountable owner and review date;
- apply the longest approved applicable period;
- suspend disposal under legal hold, audit, dispute, claim, investigation, open procedure or unresolved correction;
- preserve authenticity, integrity, legibility and authority access requirements;
- never let the agent delete records.

This reference is not legal/tax advice and must be reviewed for the exact operation.
