# Structured Handoffs

| Need | Handoff | Required return evidence |
|---|---|---|
| Approved movement, commercial terms, Incoterm, client/supplier commitment | CEO/commercial owner/Legal | Recorded decision, contract/order source and authority |
| Product identity, configuration, materials, function, weights/packing engineering facts | Engineering/Product Documentation | Exact released source/revision/applicability |
| Project/order/milestone/dependency | Project Manager | Approved scope/status/reference; no specialist customs decision |
| Price/invoice/value/payment/cost/accounting | Project Costing and authorised accounting owner | Approved records, references and reviewer decision without unnecessary payment data |
| CN/HS/TARIC, procedure, origin/preference, value | Qualified customs owner/adviser/broker | Written decision, sources/date/applicability/conditions |
| EORI/representation/customs filing | CEO/customs owner/authorised representative | Verified IDs, authority/mandate, receipt/MRN/status |
| Tax/VAT/Intrastat | Accounting/tax/Legal owner | Written applicability/treatment/threshold/filing evidence |
| Sanctions/export control/licence | Legal/qualified compliance owner | Dated scope, official sources, decision/conditions/expiry |
| Dangerous goods | Qualified DG safety adviser/shipper | Classification, packaging/marking/document/training decision |
| Transport/insurance/tracking | Authorised logistics owner/carrier/forwarder/insurer | Booking/transport document/status/POD/claim evidence |
| Another agent or employee | Named authorised recipient only | Minimum task-specific sanitised extract; no automatic repository access |

The documentation agent owns traceability and reconciliation, not the other role's decision.
