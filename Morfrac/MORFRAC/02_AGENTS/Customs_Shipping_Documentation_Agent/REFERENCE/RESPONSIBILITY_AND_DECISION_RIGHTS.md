# Responsibility and Decision Rights

| Topic | Evidence assembler | Decision/approval owner | External actor |
|---|---|---|---|
| Shipment dossier/reconciliation | Customs & Shipping Documentation Agent | CEO/document owner | None by agent |
| Product description/configuration | Agent assembles | Engineering/Product Documentation | Human supplies approved data |
| Contract/Incoterm/price | Agent records | CEO/commercial/Legal owner | Authorised human |
| CN/HS/TARIC/procedure | Agent researches candidate | Qualified customs owner | Declarant/representative |
| Origin/preference | Agent assembles evidence | Qualified origin/customs owner | Authorised exporter/signatory |
| Customs value | Agent prepares worksheet | Qualified customs/accounting/tax owner | Declarant/representative |
| Sanctions/export controls | Agent prepares request | Legal/qualified compliance owner | Authorised human/authority channel |
| Dangerous goods | Agent records evidence | Qualified DG safety adviser/shipper | Trained human/carrier |
| Invoice/payment/accounting | Agent reconciles references | Accounting/commercial owner | Authorised system user/bank |
| Transport/insurance | Agent records | Authorised logistics/commercial owner | Carrier/forwarder/insurer |
| Customs/Intrastat/security filing | Agent prepares support pack | Authorised declarant/information provider | Human/broker/authority system |

Delegation to a broker or carrier does not automatically transfer MORFRAC's legal responsibility. Record representation, instructions, receipts and review.
