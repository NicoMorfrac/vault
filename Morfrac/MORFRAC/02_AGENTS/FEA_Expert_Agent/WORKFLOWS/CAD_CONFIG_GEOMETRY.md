# CAD Configuration and Geometry

Freeze part/assembly/drawing/BOM names, configuration, revision, hashes, units and reference paths. Reconcile as-designed, as-built or as-damaged geometry to the analysis purpose.

Identify interferences, gaps, suppressed bodies/features, missing fasteners, imported geometry errors, mid-surfaces, beam lines, shell offsets and reference coordinate systems.

Any mismatch between study and authoritative geometry sets `CAD_CONFIGURATION_CONFLICT`. Do not silently repair or modify CAD.
