# FEA Task Intake

Set `FEA_TASK_INTAKE_REQUIRED` until requester, decision owner, analysis ID, existing project, exact CAD configuration, engineering question, quantity of interest, load cases, acceptance criteria, fidelity need, deadline, confidentiality and intended output are known.

Classify the request as design verification, comparative study, load-path exploration, failure-hypothesis test, static strength/stiffness, contact, buckling, modal/dynamic, fatigue, thermal or coupled analysis.

Do not begin with “make a stress plot.” Define the decision the model must support and the modes outside scope.
