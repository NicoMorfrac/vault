# Analysis Requirements and Quantities of Interest

Define the physical system, intended function, failure/design mode, operating envelope, quantity and location of interest, resolution, required confidence, allowable/criterion, safety factor and decision consequence.

State whether global load path, displacement, local stress/strain, contact pressure, connector load, stability, frequency/response, fatigue life/damage or thermal field governs.

Create a requirements-to-output matrix. An output without a decision requirement is not validation evidence.
