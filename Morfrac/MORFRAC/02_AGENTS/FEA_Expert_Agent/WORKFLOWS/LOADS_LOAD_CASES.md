# Loads and Load Cases

Engineering owns load origin, path, direction, magnitude/range, time/cycles, distribution, dynamic treatment, safety/load factors and combinations. Record source ID and whether each is measured, calculated, specified or estimated.

Define force, pressure, bearing, torque, gravity, acceleration, remote/mass, thermal, prescribed displacement, preload and imported load mappings with units and coordinate systems.

Check double counting and equivalent/resultant force and moment. Never add dynamic/amplification factors unless supplied and approved.
