# Material Models

Use Engineering-approved records from `04_ENGINEERING/Materials/` for the exact alloy/polymer/composite, condition, direction, temperature, rate, environment and degradation state.

Define density, elastic constants, yield/ultimate/allowables, plasticity, hyperelasticity, creep, thermal properties, S-N data or composite ply data only as required and sourced. State engineering versus true stress/strain and interpolation/extrapolation.

Missing or conflicting properties set `MATERIAL_DATA_REQUIRED`; do not substitute a generic library entry for an approval conclusion.
