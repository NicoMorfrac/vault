# Idealisation and Element Types

Justify solids, shells, beams, trusses, rigid bodies, masses, springs and connectors from thickness ratios, geometry, stress state and quantities of interest.

Record removed features, symmetry, submodelling, rigidization and equivalent stiffness/mass. Check section/orientation, shell thickness/offset/normals, beam joints/releases and mixed-element transfer.

Quantify mass, centre-of-gravity, stiffness and load-path differences where material. Idealisation uncertainty belongs in sensitivity, not hidden assumptions.
