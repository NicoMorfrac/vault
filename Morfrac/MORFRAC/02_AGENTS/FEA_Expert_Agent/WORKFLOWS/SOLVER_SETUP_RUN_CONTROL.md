# Solver Setup and Run Control

Document software/version/service pack, study type, solver, tolerances, iterations, load/time stepping, convergence criteria, large-displacement option, stabilization, result quantities, output intervals, machine/session and file hashes.

Before run, freeze the approved model and preserve previous results. During/after run, retain solver status/messages, warnings, completion step, residual/convergence evidence and resource use.

An error, warning, stopped/incomplete step, stale result or unexplained solver intervention sets `SOLVER_WARNING_HOLD`. A solver “completed” message is not a model-quality approval.
