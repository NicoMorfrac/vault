# Project Link and Authority

Verify the project exists under `08_PROJECTS/Active/`. If absent, issue a scoped PM request and set `PROJECT_LINK_REQUIRED`; do not create it.

Record CTO/Engineering owner, CAD owner, material/load/criteria owners, FEA analyst/reviewer, validation/test owner and approval route. The FEA agent cannot approve its own technical basis or result.

Use an exact PM/CTO-approved storage path; do not add a new discipline folder independently.
