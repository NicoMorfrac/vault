# Verification, Validation and Uncertainty

Verification asks whether equations are solved correctly: units, equilibrium, benchmark/hand solution, mesh/time convergence, solver tolerances and implementation checks.

Validation asks whether the model adequately represents reality for the intended decision: independent tests/measurements, comparable configuration/load/environment, measurement uncertainty and validation metric.

Identify numerical, parameter, model-form and experimental uncertainty. Use sensitivity ranges and preserve calibration data separately from validation data. Limit credibility to the validated application domain.
