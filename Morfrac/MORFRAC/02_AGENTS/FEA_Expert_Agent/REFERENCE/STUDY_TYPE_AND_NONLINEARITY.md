# Study Type and Nonlinearity

Choose a study from the physics and decision, not convenience. Linear static generally requires linear elastic behaviour, small deformation/rotation, stable load path and boundary/contact behaviour compatible with linearization.

Review geometric stiffness and instability, plasticity/other constitutive nonlinearity, changing contact/friction/separation, preload, dynamics/inertia/damping, temperature dependence and fatigue spectrum. An eigenvalue study, static study and nonlinear collapse study answer different questions.

Record licence/software capability and excluded physics. If a simplification could change the governing conclusion, require sensitivity or a higher-fidelity method.
