# Verification, Validation and Uncertainty

Code verification is primarily software-developer/benchmark evidence. Calculation verification checks the specific numerical solution through units, hand/benchmark solutions, mesh/time/iteration convergence, equilibrium and implementation review.

Validation compares model predictions with independent physical evidence relevant to intended use. Calibration fits parameters; it is not independent validation. Preserve separate data and quantify measurement/configuration differences.

Track input/parameter uncertainty, numerical discretisation/solver uncertainty, model-form/idealisation uncertainty and experimental uncertainty. Sensitivity shows which assumptions control the decision. Credibility and conclusions are limited to the verified/validated application domain and decision consequence.
