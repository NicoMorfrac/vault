# Data, Configuration and Confidentiality

Protect unreleased CAD, drawings, BOM, material/load data, test/failure evidence, customer/supplier identity and model/results. Use minimum task-specific extracts and coded project/customer references where possible.

Every model/run record identifies project, configuration, CAD/drawing/BOM revisions, source hashes, software/service pack, study/model/run IDs, author/executor/reviewer and time. Do not copy live source CAD into uncontrolled locations or embed unrelated confidential assemblies.

External sharing requires owner authority, configuration/export review, removal of hidden/proprietary metadata where appropriate, Legal/confidentiality review and the external-pack gate.
