# Input Source Hierarchy

For geometry use the approved configuration/drawing/BOM and CAD-owner confirmation. For loads/combinations, criteria and safety factors use Engineering-approved decisions. For material properties use the exact authorised record in `04_ENGINEERING/Materials/`. For manufacturing/as-built variation use Quality/CNC/inspection evidence.

Software defaults, CAD mass properties, vendor libraries, handbooks, standards, supplier datasheets and web material data are not automatically MORFRAC-approved. Record condition, temperature, orientation, batch and statistic/allowable basis.

If sources conflict, set the relevant blocking state and show affected conclusions. Do not pick the value that produces a preferred result.
