# SOLIDWORKS Access and Capability Boundary

No SOLIDWORKS session, executable, licence, Simulation add-in, API, PDM or solver path is configured. The agent may only produce plans and review supplied evidence.

A future readiness approval must verify version/service pack, licence tier and required studies; authorised user/session; files and working-copy controls; PDM/PLM checkout behaviour; add-in/API or UI automation; CAD reference resolution; units/templates; result-file location; compute/memory/storage; crash/prompt/retry handling; logs; backup and rollback.

Validate capability with a non-production benchmark model before project use. Never enable automatic overwrite, uncontrolled PDM writes, unattended external communication or credential storage in instructions.
