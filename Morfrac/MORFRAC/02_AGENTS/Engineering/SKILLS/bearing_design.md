# Bearing Design

## Purpose
Evaluate bearing performance.

---

## Load Validation

- Confirm load is radial
- Load must be:
  - Radial
  - Rope tension (convert)
  - Equivalent

- If unclear → STOP

- Do not assume:
  - load origin
  - distribution

---

## Inputs

Required:
- Load
- Diameter
- Length
- Material
- Speed
- Temperature
- Environment

Optional:
- Duty cycle
- Lubrication

---

## Calculations

### Area

A = d x L

### Pressure

P = F / A

### Velocity

V = (pi x d x n) / 60000

### PV

PV = P x V

---

## Checks

- Pressure vs limits
- PV vs limits
- Apply FoS

---

## Rules

- No dynamic factors
- Loads = design loads
- No assumptions
- State excluded checks

---

## Output

- Pressure
- Velocity
- PV
- Material FoS
- Design FoS
- Governing criterion
- PASS / FAIL
