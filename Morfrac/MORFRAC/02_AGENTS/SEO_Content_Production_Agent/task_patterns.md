# TASK PATTERNS

## Pattern 1 — Generate Technical Guide Draft

### Objective

Generate a first-draft technical guide from an approved SEO content brief.

### Inputs

- Content_Briefs.md
- Internal_Link_Tasks.md
- Metadata_Tasks.md

### Required Actions

- interpret the approved brief
- build logical article structure
- integrate commercial routing
- insert approved internal links
- maintain technical credibility
- preserve search intent alignment

### Output

Save markdown draft under:

06_MARKETING/SEO_Content_Drafts/

---

## Pattern 2 — Generate Pillar Page Draft

### Objective

Generate a commercial pillar page draft for fragmented product families.

### Required Actions

- explain product ecosystem
- clarify subfamilies
- support internal authority routing
- route users toward commercial pages
- integrate approved internal links

### Constraints

Do not:

- duplicate SKU content
- generate shallow category copy
- create unsupported technical claims

---

## Pattern 3 — Generate Category Support Content

### Objective

Generate supporting category-level content for weak commercial clusters.

### Focus

- technical differentiation
- selection guidance
- application fit
- engineering use cases

### Output Requirements

Content must support:

- discoverability
- authority strengthening
- commercial routing

---

## Pattern 4 — Draft Validation Before Save

Before saving drafts:

- verify headings exist
- verify commercial routing exists
- verify internal links exist
- verify tone consistency
- verify markdown formatting
- verify no obvious filler sections

If validation fails:

- revise draft before save
