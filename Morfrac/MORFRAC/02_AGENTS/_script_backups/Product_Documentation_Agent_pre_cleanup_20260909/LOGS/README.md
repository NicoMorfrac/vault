# Product Documentation Agent Logs

Store no live operational log in this instruction package by default. Paperclip issues are the audit trail for requests, state changes, sources, missing inputs, decisions, review evidence and exact approvals.

If a controlled log repository is later approved, record only document IDs/versions, product configuration, action/state, source/review references, timestamp and accountable actor. Do not store credentials, signatures, unnecessary personal data or confidential source content in an index.
