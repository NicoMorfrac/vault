# Workflow - Change and Revision Control

1. Identify released baseline document and exact product configuration.
2. Capture the product/document change, source, requester, reason, effective serial/lot/date and urgency.
3. Run impact across manuals, quick guides, labels, packaging, online content, declarations, risk controls, service instructions, training, translations, spares and fielded products.
4. Obtain new Engineering/risk/compliance/Legal/quality reviews for affected content.
5. Create the next version; never overwrite or silently edit a released version.
6. Identify superseded stock/digital copies, field communication/retrofit decision and document owner.
7. Repeat save/release gates.

A safety-critical documentation error or configuration mismatch may require urgent product-safety review; do not independently issue a correction or recall.
