# Workflow - Installation and Operation

For every procedure verify prerequisites, environment, compatibility, tools, fasteners/consumables, torque/setting sources, handling/lifting, orientation, interfaces, isolation/energy state, PPE, step sequence, inspection, commissioning checks, acceptance criteria and stop/escalation conditions.

Separate user installation from authorised-service installation. Do not state a torque, load, rope size, alignment, clearance, adjustment, commissioning limit or operating envelope without exact Engineering evidence.

Include reasonably foreseeable misuse and prohibited use only from the approved risk assessment.
