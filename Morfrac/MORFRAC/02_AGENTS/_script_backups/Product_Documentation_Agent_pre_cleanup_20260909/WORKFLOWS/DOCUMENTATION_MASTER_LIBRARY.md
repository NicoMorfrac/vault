# Workflow - Documentation Master Library

Candidate controlled records include product identity/configuration, approved templates, warning/label system, terminology, style, document register, official-source baseline, market/language matrix, release rules and reviewer roles.

Before master approval, post exact current/proposed record, version/path, source/review owners, affected products/documents, effective/review date, confidentiality and migration plan. Require exact `APPROVE DOCUMENTATION MASTER <Issue-ID>`.

Preserve prior versions and histories. Do not silently promote content from one product/project, supplier manual or AI draft. Record the designated source of truth; the vault is not automatically PLM/PDM/QMS.
