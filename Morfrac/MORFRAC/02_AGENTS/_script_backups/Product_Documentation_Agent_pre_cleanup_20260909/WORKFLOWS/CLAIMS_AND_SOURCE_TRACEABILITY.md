# Workflow - Claims and Source Traceability

Create a claims register for each specification, limit, compatibility statement, performance claim, compliance statement, warning, interval, warranty statement and procedure-critical value.

Record exact claim, document location, product configuration, source/revision/page, evidence type, owner/reviewer, approval and expiry/change trigger.

Do not strengthen source wording. `Target`, `tested sample`, `calculated`, `estimated`, `up to`, `under specified conditions` and `passes for supplied inputs` must not become an unconditional product promise.

Marketing and proposal claims must agree with released documentation and evidence. A conflict blocks release.
