# Tooling and assembly

For every operation identify tool manufacturer/product code, type, cutting diameter at engagement, corner/nose geometry, grade/coating, effective teeth, flute/cutting length, shank, holder/arbor, extensions, gauge length, overhang/stick-out, assembly limits, runout requirement, balance class where applicable and tool number.

Check reach, flute exposure, holder/shank clearances, neck strength, pullout/retention and machine interface. Tool-tip-only geometry is insufficient for collision verification.

Record source revision/date and life/change criteria. Missing exact assembly data sets `TOOL_ASSEMBLY_DATA_REQUIRED`.
