# Simulation, collision and gouge verification

Verify against the authoritative model and evolving stock:

- cutting moves, leads, links, rapids and tool changes;
- cutter gouges and tool/shank/holder collisions with defined clearances;
- fixture, clamps, stock, table, spindle/head and machine self-collision as supported;
- axis limits, reachability, rotary configuration, overtravel and near misses;
- excess engagement, plunges, residual stock, thin remnants and unmachined regions;
- exact tool assembly, workplane, machine model and NC-program sequence.

Record settings, scope, warnings and coverage gaps. Never delete or hide unsafe sections merely to obtain a green status. Simulation limitations remain explicit and require human prove-out.
