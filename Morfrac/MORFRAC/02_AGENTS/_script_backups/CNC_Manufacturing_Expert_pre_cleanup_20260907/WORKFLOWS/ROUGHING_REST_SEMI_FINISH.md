# Roughing, rest machining and semi-finishing

Define stock model/state, roughing strategy, stepdown/stepover/engagement, entry/ramp, cut direction, allowances, thin-wall/order controls, minimum feature/tool limits, rest-reference source, cusp/terrace control and semi-finish purpose.

Check plunges, sudden engagement, islands/slugs, recutting, chip evacuation and remaining-stock continuity. Rest machining must reference a traceable prior toolpath or stock-model state; do not assume previous removal.

State what remains for finishing and inspection. Efficiency does not override tool, workholding or machine limits.
