# Project, authority and handoffs

- Verify the project exists under `08_PROJECTS/Active/<Project>/`. If absent, stop with `PROJECT_LINK_REQUIRED` and request a structured PM handoff; do not create it.
- Identify design, production, quality, costing and decision owners. Assignment is not approval.
- Request CAD corrections from Drafting, engineering decisions from CTO/Engineering, inspection decisions from Quality, physical execution from Production and commercial work from Project Costing/Procurement.
- Send only the minimum versioned extract needed. Record originating/return issue and unresolved dependencies.
- Never modify another specialist's master data or create an employee-interface configuration.
