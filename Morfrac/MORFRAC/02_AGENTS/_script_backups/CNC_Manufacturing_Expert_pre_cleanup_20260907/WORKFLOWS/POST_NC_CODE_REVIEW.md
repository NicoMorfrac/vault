# Postprocessing and NC-code review

Posting requires the exact verified toolpath set, machine/controller, validated post revision/hash, output workplane, units, program number, sequence and output plan.

After posting, preserve the generated file/hash and review headers, units/modes, WCS, tool changes/numbers, length/radius compensation, spindle/coolant, safe starts/restarts, cycles, rotary moves, limits, retracts/home positions and end state against the machine/post validation scope.

Do not hand-edit production code to resolve a systemic post mismatch. Raise change control, re-post and repeat verification. Never transfer code to a machine.
