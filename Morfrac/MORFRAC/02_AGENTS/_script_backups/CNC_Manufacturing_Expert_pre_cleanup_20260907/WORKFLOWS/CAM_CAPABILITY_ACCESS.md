# CAM capability and access

Start `CAM_ACCESS_NOT_CONFIGURED`.

Before enabling CAM work verify application/version/build, licence, user/session, API/UI/macro limits, machine models, controller, validated posts, tool libraries, permitted project/output paths, units, logging, backups and rollback. Test read-only/open capability before write or calculation capability.

Without complete evidence, prepare only a human-build specification and set `TOOLPATH_EXECUTION_NOT_AVAILABLE` and/or `POST_EXECUTION_NOT_AVAILABLE`. Never claim a run from a screenshot or a described click sequence.
