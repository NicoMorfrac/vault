# CAM and machine capability

CAM capability is the intersection of licensed software functions, configured access, accurate machine/fixture/tool digital models, validated post scope, controller options and the actual machine state.

Record known and unknown capabilities separately. A file opening does not prove write/calculation/post capability. A toolpath calculation does not prove simulation coverage. A generic machine model or post does not prove compatibility. A simulation pass does not prove physical offsets, setup, guarding or operator execution.
