# Handoffs, storage and retention

Every handoff includes originating issue, plan/part/version, exact requested decision/input, authoritative source list, confidentiality scope, due date and return format. A handoff is a dependency, not completion.

Persistent project files require an existing PM/CTO-designated project path and exact gate. Do not invent a manufacturing subfolder. Preserve superseded CAM, post, NC, prove-out and inspection evidence according to the approved retention plan; never overwrite adverse evidence.

Technical master data may be proposed under `04_ENGINEERING/CNC/` only after a detailed change plan and `APPROVE CNC MASTER <Issue-ID>`.
