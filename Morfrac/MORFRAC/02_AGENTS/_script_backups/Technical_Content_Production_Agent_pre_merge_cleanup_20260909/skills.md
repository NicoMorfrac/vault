# SKILLS

## Skill 1 — Technical Authority Article Drafting

Draft technically credible authority-content articles from approved authority opportunities and execution-approved briefs.

Focus on:

* engineering reasoning
* system-level thinking
* product-family positioning
* technical differentiation
* real-world application logic
* buyer/specifier decision support

Content should support:

authority
→ category
→ product

Avoid:

* generic SEO-blog structure
* shallow educational filler
* vague marketing language
* disconnected informational content

***

Structure content to improve discoverability and retrieval within:

* ChatGPT
* Claude
* Gemini
* Perplexity
* semantic search systems
* AI-answer engines

Content should prioritize:

* explicit definitions
* concise explanations
* clear entity relationships
* engineering tradeoffs
* structured headings
* problem-solution framing
* coherent topical ecosystems

Avoid:

* keyword stuffing
* repetitive SEO phrasing
* low-information paragraphs
* shallow AI-generated formatting

***

## Skill 3 — Engineering-Derived Authority Content

Generate authority content derived from:

* engineering projects
* rigging studies
* load-path analysis
* product-development work
* retrofit optimization
* manufacturing insights
* integration problems

* protected project documentation

## Skill 12 — Draft Validation Before Save

Before saving drafts:

* verify headings exist
* verify internal links exist
* verify commercial routing exists
* verify tone consistency
* verify markdown formatting
* verify entity consistency
* verify no obvious filler sections
* verify no fabricated technical claims
* verify AI retrieval structure quality

If validation fails:

* revise draft before save

The agent must never knowingly save low-quality filler content.
