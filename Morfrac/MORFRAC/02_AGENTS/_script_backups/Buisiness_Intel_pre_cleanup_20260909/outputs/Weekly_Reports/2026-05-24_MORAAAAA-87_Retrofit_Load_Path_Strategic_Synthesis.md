- Willingness to pay is plausible where failure consequences include mast-loss risk, water ingress, deck-core damage, rework, liner/cabinetry surgery, schedule delay, and yard liability.
- The best commercial form is not a generic consulting offer. It is a bounded retrofit engineering package:
  - remote pre-fit review
  - inspection and information-capture checklist
  - load-path validation
  - backing/reinforcement concept
  - approved hardware/integration configuration
  - install drawing and documentation package
- This is more repeatable than one-off bespoke advice and better aligned with MORFRAC's hardware ecosystem.

## Strategic Importance

- It is strategically stronger than commodity hardware expansion because the pain is driven by uncertainty, integration difficulty, and liability, not by simple part availability.
- It also creates a defensible wedge into yards, riggers, refit specialists, and OEM-adjacent technical partners who need judgment and documentation, not just components.

## Recommended Actions

1. Define a productized offer for refit yards and riggers called a retrofit load-path review or deck-hardware integration package.
2. Build a qualification gate that rejects under-specified cases unless minimum inputs are provided: geometry, access limits, photos, substrate clues, load case, intended hardware, and service objective.
3. Create a standard evidence-capture kit:
   - photo angles
   - deck/core questions
   - hidden-structure checklist
   - leak/corrosion indicators
   - access and liner constraints
4. Pilot the offer on a narrow problem set first:
   - through-deck padeye replacements
   - chainplate-adjacent deck hardware integration
   - winch/organizer relocation where backing and load transfer are uncertain
5. Tie the service to hardware pull-through instead of offering engineering in isolation where possible.
6. Validate willingness to pay with targeted interviews of refit yards, riggers, and integrators before scaling.
7. Build technical authority assets around the same pain themes so the market sees MORFRAC as the company that explains and resolves retrofit load-path uncertainty.
