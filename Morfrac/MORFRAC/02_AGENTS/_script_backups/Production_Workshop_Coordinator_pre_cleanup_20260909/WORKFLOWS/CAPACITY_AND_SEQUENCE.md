# Capacity and sequence

Use supplied calendars/timezone, work-center capacity, existing allocations, authorised staff availability, maintenance, setup/cleanup, run duration, inspection windows and precedence. Do not assume an eight-hour day, 100% efficiency, unlimited machines or overtime.

Build a finite proposal with explicit machine and labour constraints. Do not sum aggregate labour duration as machine occupancy. Do not book the same exclusive resource twice. Different batch sizes, alternative machines or simultaneous work require a validated basis and owner approval.

Respect PM priorities. Show competing feasible options, assumptions, unsupported windows and milestone impact. A priority conflict routes to PM; no customer commitment or external schedule change occurs. Use `TEMPLATES/CAPACITY_SEQUENCE.md`.
