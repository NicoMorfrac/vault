# Official workflow reference baseline

Checked 2026-08-30. These Odoo 19.0 pages provide terminology for a possible future integration, not evidence of MORFRAC's installed version or permission to operate its systems.

- Work-center capacity, calendars and availability: https://www.odoo.com/documentation/19.0/applications/inventory_and_mrp/manufacturing/advanced_configuration/using_work_centers.html
- Work-order and manufacturing-order workflow distinctions: https://www.odoo.com/documentation/19.0/applications/inventory_and_mrp/manufacturing/shop_floor/shop_floor_overview.html
- Operator time versus work-order duration: https://www.odoo.com/documentation/19.0/applications/inventory_and_mrp/manufacturing/shop_floor/shop_floor_tracking.html
- Quality-check workflow: https://www.odoo.com/documentation/19.0/applications/inventory_and_mrp/quality/quality_management/quality_checks.html

MORFRAC policies in `00_SYSTEM` and approved PM/CNC/Quality/Costing records govern this coordinator. Documentation defaults are never MORFRAC capacity, timing, inspection or staffing values. No external machine safety/operating procedure is substituted for approved site instructions.
