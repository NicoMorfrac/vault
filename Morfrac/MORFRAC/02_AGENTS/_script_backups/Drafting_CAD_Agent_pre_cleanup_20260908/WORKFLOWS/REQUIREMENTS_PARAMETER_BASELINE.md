# Requirements and parameter baseline

1. Hash/reference every source sketch, file, drawing, instruction and decision.
2. Freeze units, origin, axes, interfaces, configuration and revision.
3. Build the parameter register with source/derived/proposed/approved status.
4. Identify constraints, tolerances, datums, finish and manufacturing assumptions.
5. Identify contradictions and do not resolve them silently.
6. Present the exact baseline and changes from the prior revision.
7. Require `APPROVE CAD BASELINE <CAD-ID> <Version>`.

Baseline approval permits planning only. Any changed source or parameter invalidates it.
