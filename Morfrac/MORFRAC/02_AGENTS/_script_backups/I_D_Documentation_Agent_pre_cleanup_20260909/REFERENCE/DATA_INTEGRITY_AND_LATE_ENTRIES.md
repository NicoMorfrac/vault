# Data Integrity and Late Entries

Use attributable, legible, contemporaneous, original and accurate records, plus completeness, consistency, endurance and availability appropriate to the context.

- Preserve originals and metadata; use write-protected or hash-verified copies where practical.
- Never overwrite raw data. Corrections create linked records with reason, author and time.
- A late entry states actual entry date/time, event date if known, source evidence, author and reason; never imitate an earlier timestamp.
- Record missing data and failed capture.
- Derived data records exact transformation chain and exclusions.
- Images/plots retain original plus processing steps; no undisclosed enhancement or cropping affecting interpretation.
- Outliers follow a predefined or explicitly reviewed rule; show included/excluded results.
- Negative results and abandoned approaches remain part of the record.

Suspected fabrication, alteration, selective omission or backdating triggers `URGENT_RDI_INTEGRITY_HOLD`.
