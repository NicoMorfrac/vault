# Logs

Use Paperclip issues as the operational audit trail. Do not duplicate live R&D data, designs, test results, failures, personnel, costs, tax/grant material, partner information, IP or credentials in this instruction-package log.

After approved persistence, record RDI project/version, source/configuration/hashes, reviews, files/hashes, approval references, human external receipt, supersession and close/retention status in the controlled R&D repository.
