# Periodic Technical Reporting

For the stated period, report approved baseline, activities performed, evidence-backed progress, milestone/deliverable status, results, negative results, deviations/changes, risks, resources/cost references, IP/confidentiality, external obligations and next-period plan.

Separate planned versus actual and technical evidence versus management interpretation. Quantitative claims cite exact source/configuration. Do not claim percentage complete from spend alone.

Internal reports remain `PERIODIC_REPORT_DRAFT` until reviewed; external requirements use the specific programme/recipient template.
