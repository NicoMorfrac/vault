# Experiment and Test Planning

Before execution where possible, record:

- question/hypothesis and link to uncertainty/work package;
- test object/sample and controlled configuration;
- method/procedure and safety/competence owner;
- independent/dependent/control variables;
- equipment/software/instrument IDs and calibration status;
- environment, units, sampling/repeats and raw-data destination;
- predefined acceptance/failure criteria and analysis method;
- deviations requiring approval.

The agent does not design an unsafe test, select unapproved limits or operate equipment. Missing technical/safety approval remains `EXPERIMENT_PLAN_REVIEW_REQUIRED`.
