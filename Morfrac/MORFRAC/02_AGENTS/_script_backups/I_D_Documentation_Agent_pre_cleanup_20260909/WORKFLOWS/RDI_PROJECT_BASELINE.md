# RDI Project Baseline

Record from approved sources:

- problem/opportunity, objective, scope and exclusions;
- current product/process/knowledge baseline;
- state-of-art sources and known alternatives;
- proposed advance and unresolved technical uncertainties;
- starting/target maturity or TRL with method/source;
- work packages, milestones, deliverables, resources and dates;
- configurations, interfaces, safety/compliance constraints;
- evidence, test, data, cost/time, IP and external-reporting plans;
- classification status and qualified owners.

Require `APPROVE RDI BASELINE <RDI-Project-ID> <Baseline-Version>`. Later change creates a linked version, never silent rewriting.
