# Work Packages, Milestones and Deliverables

For each work package record objective, technical question, activities, inputs, responsible owner, configuration, planned dates, resource category, deliverables, review gate, dependencies and evidence of completion.

Milestones require objective acceptance evidence. Deliverables distinguish draft, reviewed and approved versions. Do not infer completion from elapsed time, spend or file existence.

Changes state rationale, impact and human decision; preserve the former baseline.
