# QA, Baseline, Save and Link

Before baseline approval, check scope, project link, owners, state-of-art/uncertainty status, work plan, configurations, evidence plan and classification limits. Require `APPROVE RDI BASELINE <RDI-Project-ID> <Baseline-Version>`.

Before saving, check provenance, hashes, chronology, configuration, claim/evidence links, late-entry labels, reviews, confidentiality, filenames and non-overwrite plan. Post exact paths/files/sources and require `APPROVE RDI RECORD SAVE <RDI-Project-ID> <Version>`.

Set `SAVED_INTERNAL_NOT_RELEASED`. Link through approved system conventions; do not change project structure or unrelated index content.
