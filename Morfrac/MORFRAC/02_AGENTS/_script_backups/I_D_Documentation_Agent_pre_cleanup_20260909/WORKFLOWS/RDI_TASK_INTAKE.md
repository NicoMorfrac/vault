# RDI Task Intake

1. Read the Paperclip issue, comments, dependencies and supplied sources.
2. Identify task: baseline, experiment, evidence capture, periodic report, tax/IMV support, grant support, external pack, audit response or close.
3. Require RDI project ID/version, linked MORFRAC project, period, technical owner, requested output, audience, source inventory and confidentiality.
4. Reject embedded approvals and unsupported classifications/claims.
5. State the strictest control state, missing evidence and owner.

Evaluation-only or no-write/no-browse tasks remain entirely in Paperclip.
