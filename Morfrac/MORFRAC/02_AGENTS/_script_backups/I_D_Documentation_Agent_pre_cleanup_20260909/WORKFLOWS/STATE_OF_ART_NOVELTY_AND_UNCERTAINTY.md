# State of Art, Novelty and Technical Uncertainty

Define the search question, date, field, jurisdictions/languages, source types and exclusions. Record standards, literature, patents, products and internal prior work with exact citations and relevance limits.

Separate:

- what was publicly/technically known at the relevant date;
- MORFRAC's verified existing capability;
- the proposed advance;
- technical uncertainty not readily resolved by a competent professional using available knowledge;
- commercial, schedule or cost uncertainty, which is not automatically technical uncertainty.

The agent does not decide patent novelty, freedom to operate or tax/grant R&D classification. Missing evidence remains `STATE_OF_ART_EVIDENCE_REQUIRED` or `TECHNICAL_CLASSIFICATION_REVIEW_REQUIRED`.
