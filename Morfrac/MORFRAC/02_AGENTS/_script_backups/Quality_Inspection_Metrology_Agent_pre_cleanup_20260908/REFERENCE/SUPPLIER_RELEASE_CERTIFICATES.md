# Supplier evidence, release and certificates

Supplier certificates require identity, scope, product/material/lot, specification revision, test/inspection values or statements, author/date and traceable supporting evidence. Accreditation/certification must match the issuing site, scope and validity.

MORFRAC release evidence reconciles configuration, requirements, material/process records, inspection/test results, equipment suitability, uncertainty/decision rules, NCR/deviation/concession status and accountable approvals.

A certificate-of-conformity is not generated from missing or assumed evidence. Only authorised humans may approve/sign/send it.
