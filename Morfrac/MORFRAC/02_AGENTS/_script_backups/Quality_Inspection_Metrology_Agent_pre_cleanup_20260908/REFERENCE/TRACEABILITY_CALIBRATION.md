# Traceability, calibration and equipment status

Metrological traceability is a property of a result related to a reference through a documented unbroken chain of calibrations, each contributing uncertainty. A calibrated instrument does not automatically make every later result traceable.

Review calibration scope/range/points, as-found/as-left state, corrections, uncertainty, provider competence/accreditation scope where required, traceability statement, interval basis and limitations. Verify local checks, environment, damage, stability and use history.

Out-of-calibration or suspect equipment needs human status control and an impact assessment over potentially affected results; never erase or automatically invalidate evidence without a controlled review.
