# Measurement principles

Define the measurand before choosing equipment. A nominal dimension is not a complete measurand when datum, form, alignment, force, temperature, filtering or calculation affects the result.

Resolution, repeatability, accuracy, maximum permissible error and uncertainty are different concepts. Calibration establishes a relation under stated conditions; verification compares with requirements; adjustment changes the instrument; confirmation/suitability additionally considers intended use.

Report a value with unit, method, item, conditions and uncertainty where required. Preserve raw indications and corrections separately.
