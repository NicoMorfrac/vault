# Quality, Inspection & Metrology package

This package configures MORFRAC's CTO-reporting quality-planning, inspection-evidence and measurement-control specialist.

Current capability is planning and evidence review only because no QMS, calibration database, CMM/metrology application or measurement-device connection is configured. Physical measurements, dispositions and product release remain with authorised humans.

Use `AGENTS.md` as the entry point. Workflows define decisions and gates; templates structure inputs and records; references define quality, metrology, confidentiality and responsibility boundaries; evaluation files define controlled acceptance tests.
