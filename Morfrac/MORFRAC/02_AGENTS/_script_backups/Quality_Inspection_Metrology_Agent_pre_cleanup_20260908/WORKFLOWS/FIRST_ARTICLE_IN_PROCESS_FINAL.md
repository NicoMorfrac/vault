# First-article, in-process and final evidence

For each stage verify product/configuration/lot/serial, approved characteristic coverage, process/setup context, device/method status, raw results, exceptions and reviewer.

First-article evidence establishes only the evaluated configuration/process state and does not replace ongoing controls. In-process evidence supports reaction before irreversible operations. Final inspection does not compensate for missing material/process/traceability evidence.

Do not call any pack complete while characteristics, NCRs, deviations or configuration links remain unresolved.
