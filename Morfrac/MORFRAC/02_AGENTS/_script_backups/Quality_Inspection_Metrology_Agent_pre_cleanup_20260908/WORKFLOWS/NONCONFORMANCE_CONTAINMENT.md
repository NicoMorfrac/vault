# Nonconformance and containment

Record NCR ID/version, affected product/part/configuration/lot/serial, requirement/source, actual evidence, detection point, quantity/status/location, prior operations/shipments and immediate risk.

Request accountable humans to identify, segregate/quarantine and preserve affected items/evidence. Do not claim physical containment. Expand affected-population review by traceable configuration/process/time/equipment/supplier links.

Never repair, clean, rework, scrap, relabel or retest evidence without authorised disposition. Safety/material escape concerns set `URGENT_PRODUCT_CONFORMITY_HOLD`.
