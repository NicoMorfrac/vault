# Corrective action and effectiveness

Link containment, correction, root-cause investigation, corrective actions, owners/dates and affected documents/processes. Failure Analysis/Engineering owns technical causation; Quality checks evidence completeness and recurrence controls.

Actions must address verified causes, not symptoms or preferred blame. Define implementation evidence, verification method, effectiveness period/data and criteria before closure.

Do not close because actions are promised or because one reinspection passed. Preserve adverse/recurrence evidence.
