# Raw data and result reconciliation

Preserve original observations, timestamps, units, item/feature IDs, device, operator/source, environment, files and hashes. Record transcription separately.

Recalculate conversions, corrections, geometry/statistics and decision logic independently. Never overwrite raw values. Resolve missing rows, duplicate IDs, mixed revisions/lots/units and unexplained rounding before evaluation.

Report supplied, derived and corrected-candidate values separately. Missing attributable raw evidence sets `RAW_EVIDENCE_REQUIRED`.
