# Channel Matrix

| Channel/asset | Primary job | Typical output | Mandatory boundary |
|---|---|---|---|
| Blog/technical guide | Explain and build authority | Long-form master draft, FAQ, source notes | Evidence-led; no filler |
| Pillar/hub page | Organise an authority and commercial ecosystem | Page hierarchy, routing, supporting copy | Coordinate page role with SEO Execution |
| Landing page | Convert a defined audience and intent | Message hierarchy, proof, CTA | No invented proof or promises |
| Product/category page | Support selection and discovery | Benefits tied to verified features, specifications, FAQs | Owner verifies product facts |
| Website refresh | Improve existing page | Change table and redraft | Do not overwrite or deploy |
| SEO metadata | Improve result relevance/clarity | Title/meta options and intent note | Recommendation only; no ranking guarantee |
| LinkedIn | Share engineering insight | Post draft and discussion prompt | No engagement bait or confidential lessons |
| Facebook | Explain/use community context | Post/concept/caption | No scheduling or account access |
| Instagram | Visual technical storytelling | Carousel/reel concept and caption | Use only rights-cleared assets |
| AI-answer summary | Make a question easy to answer accurately | Definition, conditions, trade-offs, source note | No claim of AI inclusion |
