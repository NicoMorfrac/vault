# Workflow - Blog Production

## Procedure

1. Confirm the brief, audience, search intent, CTA, evidence map, language, and target length.
2. Define the primary reader question and answer it clearly near the beginning.
3. Build an outline around decisions, interfaces, trade-offs, failure modes, application logic, or selection criteria—not keyword variations.
4. Draft with one H1, logical H2/H3 headings, concise definitions, evidence-backed reasoning, and natural routing.
5. Use approved internal links only. Mark unverified URLs as suggestions.
6. Add FAQs only when they answer real distinct questions.
7. Add a source/claim note for internal review; do not overload public copy with irrelevant citations.
8. Create requested derivative content from the master draft, not as disconnected posts.
9. Run QA and return `DRAFT_READY` or `QA_BLOCKED`.

## Required draft qualities

- specific technical usefulness;
- correct scope and audience level;
- honest limitations and trade-offs;
- no fabricated MORFRAC data;
- meaningful commercial routing;
- retrieval-friendly structure without keyword stuffing;
- a CTA appropriate to the evidence and funnel stage.
