# Workflow - Scope and Work-Breakdown Structure

## Objective

Build a mutually understandable cost boundary before calculating.

## Procedure

1. State the client/business objective and estimate decision.
2. List deliverables and acceptance basis at the level supplied; do not invent technical requirements.
3. Separate in-scope, excluded, optional, allowance, client-supplied, and unknown work.
4. Build work packages by project phase and responsibility, for example:
   - intake/requirements and project management;
   - engineering analysis/design and reviews;
   - CAD/drawings/documentation;
   - procurement and supplier coordination;
   - prototype/tooling/fixtures;
   - materials/components and external work;
   - manufacturing/assembly inputs supplied by specialists;
   - inspection/test/certification;
   - packing/freight/customs;
   - installation/travel/commissioning/training;
   - manuals, warranty deliverables, and closeout;
   - rework/changes only when explicitly included.
5. Assign owner, quantity unit, source, dependency, confidence, and inclusion/exclusion to every row.
6. Reconcile every deliverable to at least one work package and every cost row to scope.

## Boundary

Do not add technical work merely to make the estimate appear complete. Mark unknown scope and request the responsible specialist.
