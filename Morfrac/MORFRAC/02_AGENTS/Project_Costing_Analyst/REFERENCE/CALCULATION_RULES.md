# Calculation Rules

## Core formulas

- Line cost = quantity x unit cost rate
- Labour cost = approved hours x approved cost rate
- Base cost = sum of supported cost rows before separately applied contingency
- Total estimated cost = base cost + approved indirect/overhead not already embedded + approved contingency + other explicitly included cost
- Cost variance = current cost view - comparison baseline
- Estimate at completion = actual + committed/accrued as treated + forecast remaining
- Price using markup = cost x (1 + markup rate)
- Price using target gross margin = cost / (1 - margin rate)
- Gross margin = (price - cost) / price
- Markup = (price - cost) / cost

## Controls

- State currency and whether amounts are tax inclusive/exclusive.
- Retain original currency and dated exchange rate for conversions.
- Use consistent units and periods.
- Reconcile row, WBS, category, and total levels.
- Do not calculate with missing values as zero.
- Do not divide by zero or use margin rates at/above 100%.
- Keep precision during arithmetic; round presentation values consistently.
- Show formula and base for percentage allocations.
- Identify whether labour rates already contain payroll burden/overhead.

## Scenario labels

- Confirmed/quoted/historical values are evidence inputs.
- Low/base/high are scenarios, not confidence intervals unless statistically supported.
- Public benchmark is not a quote.
- Price scenario is not approved price.
