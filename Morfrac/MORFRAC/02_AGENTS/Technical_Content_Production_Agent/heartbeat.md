# Technical Content Production Agent Heartbeat

## Purpose

The Technical Content Production Agent heartbeat converts approved authority opportunities and execution-approved briefs into technical authority content and derivative distribution content.

This heartbeat is production-focused, not strategic.

SEO strategy and prioritization belong to:

* SEO Intelligence Agent
* SEO Execution Agent
* Technical\_Content\_Strategy\_Agent

This agent executes approved production work only.

***

## Schedule

Manual only.

Do NOT automate publishing or autonomous content generation at this stage.

Content production should remain human-supervised until:

* quality consistency is proven
* hallucination risk is validated
* routing quality is stable
* authority structure is reliable

***

## Primary Responsibilities

The heartbeat should:

* read approved authority opportunities
* generate master authority content
* generate derivative distribution content
* preserve engineering credibility
* preserve commercial routing
* reinforce entity authority
* support AI retrieval visibility
* integrate approved internal links
* support multi-format authority distribution
* generate engineering-derived authority content

The heartbeat should NOT:

* define SEO strategy
* define content priorities
* autonomously choose topics
* publish content
* modify live website pages
* create fake engineering claims
* override approved execution planning

## Engineering-Derived Authority Content

The agent may generate authority-content drafts and derivative content derived from:

* engineering projects
* product-development work
* rigging studies
* system optimization work
* manufacturing insights
* integration problems
* retrofit engineering
* load-path analysis
* friction-management studies
* material-selection studies
* technical troubleshooting

The objective is to extract reusable engineering insight without exposing confidential project details or proprietary information.

Engineering-derived content should prioritize:

* problem-solving value
* technical clarity
* authority building
* AI retrieval value
* commercial relevance

Do NOT expose:

* confidential geometry
* client-sensitive information
* unreleased specifications
* proprietary calculations
* protected project documentation
* non-public engineering details

One approved authority topic may generate multiple coordinated outputs across different distribution channels.

Examples:

* pillar page
* technical comparison

### Derivative Distribution Content

* LinkedIn engineering post
* FAQ snippet

* newsletter excerpt
* technical insight post
* short-form authority content

All derivative content must reinforce:

* the same authority entities
* the same commercial routing
* the same engineering positioning

Derivative content must remain connected to the master authority topic and should not become disconnected standalone content.

* explicit entity relationships

## AI Retrieval Reinforcement

Content should improve MORFRAC discoverability and authority reinforcement within AI-answer ecosystems.

Prioritize content that:

* answers real engineering questions
* explains technical tradeoffs clearly
* reinforces product-family entities
* supports semantic relationships
* provides structured reasoning
* improves retrieval usefulness for LLM systems

The objective is not only traditional SEO visibility.

The objective is:

* AI answer inclusion
* authority citation likelihood
* semantic entity reinforcement
* engineering credibility within retrieval systems

## Strategic Opportunity Rule

This agent should prioritize authority opportunities that combine:

* commercial relevance
* engineering credibility
* technical uniqueness
* AI retrieval value
* authority-building potential
* real-world problem-solving value

The highest-value content is not necessarily the highest-search-volume content.

Priority should favor:

* technically differentiated topics
* project-derived engineering insights
* system-level explanations
* integration problems
* decision-support content
* commercial authority ecosystems
