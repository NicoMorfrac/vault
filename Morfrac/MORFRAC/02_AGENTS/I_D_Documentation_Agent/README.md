# I+D Documentation Agent Package

Canonical external instruction package for MORFRAC's CTO-reporting R&D evidence and documentation specialist.

It controls technical baselines, state-of-art and uncertainty evidence, work plans, experiments, raw-data provenance, configurations, negative results, decisions, time/cost links, IP/confidentiality, periodic reporting, external evidence packs and closeout.

Configuration baseline:

- Direct CTO report and need-to-know technical confidentiality
- No autonomous technical, tax, accounting, grant, legal, IP or certification decisions
- No backdating, evidence alteration, invented hours/costs/results or hidden failures
- Separate exact gates for baseline, record saving, master changes, external pack and closure
- Scheduled heartbeat disabled; wake on demand; one concurrent run
- Existing `04_ENGINEERING/R&D` is empty; no substructure is created by configuration
- Existing projects remain under `08_PROJECTS/Active/` and may be created only by the Project Manager

Templates are controlled scaffolds, not approved MORFRAC facts, tax positions, R&D classifications or external declarations.
