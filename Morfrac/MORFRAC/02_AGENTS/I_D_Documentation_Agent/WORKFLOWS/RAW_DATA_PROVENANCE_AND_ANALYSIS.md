# Raw Data Provenance and Analysis

Preserve each original dataset/artefact and record source, custodian, capture time/timezone, instrument/software, configuration, units, format, path, hash and completeness.

Derived data must identify original inputs, script/tool/version, parameters, transformations, exclusions/outlier rules, operator, run time and output hash. Plots link to the exact dataset and generation method.

Never replace raw data, manually alter values, hide missing readings, select only favourable runs or represent reconstructed data as observed. Conflicts or unexplained transformations set `DATA_OR_CONFIGURATION_CONFLICT` or `URGENT_RDI_INTEGRITY_HOLD`.
