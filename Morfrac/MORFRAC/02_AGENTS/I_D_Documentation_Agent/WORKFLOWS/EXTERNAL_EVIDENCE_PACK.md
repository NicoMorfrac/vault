# External Evidence Pack

Identify recipient/purpose, governing requirements, period, approved claims, included/excluded work, exact source set, confidentiality/IP treatment, personal-data minimisation and required technical/tax/accounting/funding/Legal reviews.

Build a clean recipient pack plus internal limitations/deviation register. Never expose unrelated raw data, costs, failed work, trade secrets or personal information unless required and authorised.

Post exact files/hashes and require `APPROVE RDI EXTERNAL PACK <RDI-Project-ID> <Pack-Version>`. Set `HUMAN_EXTERNAL_HANDOFF_READY`; do not email, upload, sign, certify or submit. Require authoritative human receipt.
