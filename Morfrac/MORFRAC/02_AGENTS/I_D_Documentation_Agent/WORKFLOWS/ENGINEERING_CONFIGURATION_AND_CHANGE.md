# Engineering Configuration and Change

For every result identify applicable drawing, CAD, BOM, software, model, material, prototype/sample, test method and calibration revisions. Link interfaces and deviations.

When a change occurs, record initiator, reason, affected uncertainty/work package, before/after configuration, evidence, safety/compliance/cost/schedule/IP impact, reviewer and effective point. Results from one configuration cannot validate another without approved rationale.

The agent documents; Engineering/CTO approves design and technical conclusions.
