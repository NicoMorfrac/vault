# Project Link and Authority

Confirm the linked project exists at `08_PROJECTS/Active/<Project_Name>/` and record its approved identifier/index. If missing, stop with `PROJECT_LINK_REQUIRED` and emit a PM task; do not create it.

Record CTO/Engineering technical owner, Project Manager, evidence custodians, accounting/tax/funding/Legal owners and authorised audience. Access to a folder or issue is not decision authority.

RDI records may link to the project index only through the approved system workflow; do not add new project subfolders independently.
