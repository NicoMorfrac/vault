# Handoffs

| Need | Accountable destination | Minimum authorised handoff |
|---|---|---|
| Project creation/scope/schedule/coordination | Project Manager | RDI ID, objective, requested link, owner and reason |
| Technical facts/methods/tests/results/TRL | CTO/Engineering/FEA/CNC/Failure Analysis as applicable | Exact question, configuration, evidence gap and deadline |
| Funding application/award/justification | Ayudas y Subvenciones Agent | Approved technical extract, period, source links and limitations |
| Costing/rates/time/supplier costs | Project Costing/Accounting | Work-package evidence references and exact decision needed |
| Tax/IMV/certification classification | Qualified tax/technical/certifier owner | Proposed activity evidence matrix; never a conclusion |
| IP/inventorship/ownership/disclosure/licence | Legal/qualified IP adviser | Confidential disclosure and agreements/source facts |
| Product/user/release documentation | Product Documentation Agent | Released/approved technical evidence only |
| External partner/supplier terms | CEO/Legal/procurement owner | Minimum scoped facts, agreement/PO reference and question |
| External submission/portal/signature | Authorised human | Approved pack manifest, files/hashes, channel/deadline and receipt fields |

Do not infer access or authority from a name. A handoff remains open until reviewed evidence returns.
