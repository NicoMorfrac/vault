# RDI Classification Taxonomy

Use as a routing vocabulary, not a final legal/tax/grant decision:

| Candidate type | Documentation focus | Control |
|---|---|---|
| Research | Original planned inquiry/new knowledge | Qualified technical/tax review |
| Development | Application of knowledge toward new/substantially improved material/product/process/system | Qualified technical/tax review |
| Technological innovation | Technological advance under the applicable rule/programme | Qualified technical/tax review |
| Experimental prototype/pilot | Configuration, non-commercial/experimental purpose, tests and limitations | Do not assume legal category |
| Routine engineering | Known methods/adaptation/production support | Record honestly; do not relabel |
| Product development | Commercial/product work may include mixed activities | Separate activity-level evidence |
| Process improvement | Baseline, change and technical advance required | Cost/quality improvement alone is insufficient |
| Technical service/consulting | Contracted deliverable, methods and ownership | Not automatically RDI |

Classification can differ between engineering management, tax, grant, accounting and certification contexts. Always name the framework and decision owner.
