# Time, Cost and Funding Traceability

Evidence chain:

`person/resource/supplier -> date/period -> activity/work package -> output/evidence -> authorised source record -> cost/accounting reference -> funding/tax allocation decision`

Keep quantity/hours, rate, cost, payment and eligibility separate. Preserve original currency and tax basis. Record shared-resource allocation method and owner.

Check for duplicated hours/invoices/assets/deliverables across projects, grants and tax packs. Never split or reassign retrospectively without supported correction and qualified approval.

Technical documentation does not decide accounting recognition, capitalisation, eligible cost, tax base, deduction, state aid or double funding.
