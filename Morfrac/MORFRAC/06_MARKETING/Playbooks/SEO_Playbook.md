# MORFRAC SEO Playbook

## Objective

Define how to act on SEO opportunities identified by the Marketing Agent.

---

## LOW CTR FIX

Trigger:
- High impressions
- CTR <2%

Actions:

- Improve title:
  - include keyword
  - add benefit
  - add specificity

- Improve meta description:
  - clear value
  - action-oriented

- Match search intent:
  - informational vs commercial

Expected impact:
+30% to +200% CTR increase

---

## POSITION 4–10 IMPROVEMENT

Trigger:
- Page ranking between 4 and 10

Actions:

- Expand content depth
- Add internal links
- Improve headings (H1, H2)
- Add visuals / diagrams
- Improve loading speed

Expected impact:
Move to Top 3

---

## POSITION DROP RECOVERY

Trigger:
- Drop >5 positions

Actions:

- Check competitors
- Update content
- Improve freshness
- Add missing topics
- Improve backlinks

---

## NEW CONTENT OPPORTUNITY

Trigger:
- Query with impressions but no page

Actions:

- Create dedicated page
- Target exact query
- Optimize structure

---

## PAGE INTENT MISMATCH

Trigger:
- Good traffic + low engagement

Actions:

- Align content with query intent
- Remove fluff
- Improve clarity
- Add CTA

---

## INTERNAL LINKING

Always:

- Link related pages
- Use keyword anchors
- Prioritize high authority pages

---

## FINAL RULE

Do not blindly optimize everything.

Focus only on:

- high potential pages
- high traffic queries
- commercial intent content
