# HEARTBEAT.md

## Weekly Marketing Analytics Review

Every Monday morning:

1. Pull the latest website traffic data.
2. Pull the latest Search Console SEO data.
3. Compare:
   - Last 7 days vs previous 7 days
   - Last 28 days vs previous 28 days
4. Identify:
   - Traffic changes
   - SEO gains/losses
   - Top landing pages
   - Underperforming pages
   - Search query opportunities
   - Possible campaign ideas
5. Write a weekly report to:

`04_MARKETING/Analytics/Weekly_Reports`

6. If any issue is urgent, notify the CEO Agent.
